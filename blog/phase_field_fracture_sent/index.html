Phase-field fracture of a notched tension specimen

The single-edge-notched tension benchmark: a crack nucleates at the notch tip and runs straight across the plate, predicted without tracking the crack explicitly.

What it computes

The notched specimen is read from a STEP file with named faces and meshed with triangles refined along the crack path. OneSimulation solves plane-strain elasticity coupled to an AT2 damage field by staggered alternate minimisation with an irreversibility bound, for two length scales and two mesh sizes. The script that builds the STEP file comes with the notebook.

What it checks

On the finest mesh the peak force is 0.698 kN against 0.700 kN from Miehe et al. (-0.3 %), the crack runs straight across within 8 µm of the mid-plane, and the dissipated energy matches Griffith's Gc times the crack area with the mesh correction to 0.1 %.

The geometry script

The script phase_field_fracture_sent_geometry.py builds the geometry with the CAD objects of OneSimulation and writes the file. Change a dimension there, run it, and run the notebook again.

"""Geometry of the OneSimulation example "Phase-field fracture of a single-edge notched specimen".

Builds the square specimen (side 1 mm, thickness 1 mm) with the CAD objects of OneSimulation. The
notch is a sharp wedge cut in from the left side to the centre, 4.8 micrometres wide at its mouth.
The part is written to phase_field_fracture_sent.step; its faces keep the names x_min, x_max,
y_min and y_max, the two flanks of the notch are the face notch.side.
"""

from onesim.cad.d2 import Profile
from onesim.cad.d3 import Box, Prism

side, thickness, mouth = 1.0e-3, 1.0e-3, 4.8e-6
wedge = Prism(
    profile=Profile.polygon(
        [
            (-0.1 * side, (side - mouth) / 2),
            (side / 2, side / 2),
            (-0.1 * side, (side + mouth) / 2),
        ]
    ),
    height=thickness,
)
specimen = Box(length=side, width=side, height=thickness) - wedge.named("notch")
specimen.save("phase_field_fracture_sent.step")

The notebook

The complete notebook, cell by cell. Run it to produce the figures and the comparison printout.

A phase-field model replaces a sharp crack by a damage field \(d(\mathbf x)\in[0,1]\) (\(d=1\): broken) smeared over a width set by the regularisation length \(\ell\). The displacement \(\mathbf u\) and the damage minimise the total energy (AT2 model)

\[\Pi(\mathbf u,d)=\int_\Omega\Big[g(d)\,\psi^+(\boldsymbol\varepsilon)+\psi^-(\boldsymbol\varepsilon)\Big]\,\mathrm dV +\frac{G_c}{2\ell}\int_\Omega\big(d^2+\ell^2|\nabla d|^2\big)\,\mathrm dV -W_\mathrm{ext},\qquad g(d)=(1-d)^2(1-k)+k ,\]

subject to irreversibility, \(\dot d\ge0\). The second integral converges to the Griffith surface energy \(G_c\,A_\mathrm{crack}\) as \(\ell\to0\). The strain energy is split into a part \(\psi^+\) that drives the crack and a part \(\psi^-\) that does not (volumetric energy in compression), after Amor, Marigo and Maurini (J. Mech. Phys. Solids 57, 2009).

Setup (C. Miehe, M. Hofacker, F. Welschinger, Comput. Methods Appl. Mech. Eng. 199, 2010, 2765-2778): a 1 mm x 1 mm plate with a sharp notch from the left side to the centre; \(E=210\) GPa, \(\nu=0.3\), \(G_c=2.7\) N/mm, plane strain. The specimen comes from the CAD file phase_field_fracture_sent.step, written by phase_field_fracture_sent_geometry.py with the CAD objects of OneSimulation; the model lives on its cross-section.

| side | displacement | damage | |---|---|---| | y_min (bottom) | \(u_x=u_y=0\) | zero flux | | y_max (top) | \(u_x=0\), \(u_y=u\) | zero flux | | x_min, x_max | traction free | zero flux | | notch.side (both flanks) | traction free | zero flux |

Reference. The published force-displacement curve: peak force about 0.70 kN per mm thickness at \(u\approx5.5\) µm (points digitised from the figure), with a straight crack across the ligament. And the Griffith balance: the energy dissipated in forming the crack equals \(G_c\) times the 0.5 mm ligament times the thickness, up to the overestimate \(h/2\ell\) of the regularised functional on a mesh of size \(h\).

import numpy as np
from onesim.cad.exchange import load
from onesim.meshing import TriangularMesher
from onesim.physics.solid_mechanics import PhaseFieldFracture
from onesim.visualization import plots, theme

theme.set()

Geometry and mesh

load returns the solid, section its cross-section at half thickness with the names of the cut faces on its sides. Each case has its own triangle mesh: the size is \(h\) in a band of \(\pm5\ell\) around the crack plane, from \(6\ell\) in front of the notch tip to the right side, and grows to 50 µm away from it.

specimen = load("phase_field_fracture_sent.step")
side, _, thickness = specimen.size
plate = specimen.section((0, 0, 1), origin=(0, 0, thickness / 2))
faces = plate.boundaries
tip, mm = side / 2, 1e-3
cases = {
    "l = 0.0075 mm, h = l/2": (0.0075 * mm, 0.00375 * mm),
    "l = 0.015 mm, h = l/2": (0.015 * mm, 0.0075 * mm),
    "l = 0.015 mm, h = l/4": (0.015 * mm, 0.00375 * mm),
}
main = "l = 0.015 mm, h = l/4"
band = lambda ell, h: lambda p: np.minimum(
    h
    + 0.25
    * np.hypot(
        np.maximum(tip - 6 * ell - p[:, 0], 0.0),
        np.maximum(np.abs(p[:, 1] - side / 2) - 5 * ell, 0.0),
    ),
    0.05 * mm,
)
meshes = {
    label: TriangularMesher(target_size=0.05 * mm, size_field=band(ell, h)).generate(
        plate
    )
    for label, (ell, h) in cases.items()
}

fig = plots.figure(1, 2, size=(14, 6.5))
plots.geometry(
    plate, title="Cross-section of the specimen with its named sides", ax=fig[0]
)
plots.mesh(
    meshes[main],
    groups=("all",),
    legend=False,
    title=f"{main}: {meshes[main].cell_count} triangles",
    ax=fig[1],
)
plots.show()

Model

The top side is moved up in 39 steps, fine around the expected peak; the load parameter of the solver is the displacement itself. Each step alternates between equilibrium at fixed damage and the damage at fixed displacement until the damage changes by less than \(10^{-4}\).

youngs_modulus, poisson_ratio, toughness = 210e9, 0.3, 2700.0
lift = (
    np.r_[
        0.0,
        np.arange(0.5e-3, 4.01e-3, 0.5e-3),
        np.arange(4.25e-3, 5.0e-3, 0.25e-3),
        np.arange(5.0e-3, 6.31e-3, 0.05e-3),
    ]
    * mm
)
results = {
    label: PhaseFieldFracture(
        youngs_modulus=youngs_modulus,
        poisson_ratio=poisson_ratio,
        fracture_energy=toughness,
        length_scale=ell,
        thickness=thickness,
    ).solve(
        mesh=meshes[label],
        times=lift,
        tolerance=1e-4,
        max_iterations=5000,
        displacements=(
            (faces.y_min, "x", 0.0),
            (faces.y_min, "y", 0.0),
            (faces.y_max, "x", 0.0),
            (faces.y_max, "y", lambda t: t),
        ),
        tractions=(
            (faces.x_min, (0.0, 0.0)),
            (faces.x_max, (0.0, 0.0)),
            (faces["notch.side"], (0.0, 0.0)),
        ),
    )
    for label, (ell, h) in cases.items()
}
force = {
    label: result.reactions[:, np.isclose(result.coordinates[:, 1], side), 1].sum(
        axis=1
    )
    for label, result in results.items()
}
peak = {label: int(np.argmax(values)) for label, values in force.items()}

Going further

Change the notch in phase_field_fracture_sent_geometry.py and write the STEP file again, or move the top side sideways instead of up (the shear test of Miehe et al.): the crack then curves downwards. Try a smaller \(\ell\) together with a finer band.
