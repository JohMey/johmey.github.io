Homogenized permeability of a sphere packing

Porosity and Darcy permeability of a simple cubic packing of spheres, homogenized from the 3D creeping flow through one periodic unit cell.

What it computes

A quarter of the unit cell is read from STEP files for five solid fractions and meshed with tetrahedra whose two periodic faces match. OneSimulation solves the 3D Stokes flow driven by a uniform pressure gradient with Taylor-Hood elements, periodic along the flow and with shear-free mirror planes, and derives porosity, permeability and the drag coefficient. The script that builds the STEP files comes with the notebook.

What it checks

The drag coefficient K* agrees with Zick and Homsy (1982) within 1.4 % to 2.3 % for solid fractions 0.064 to 0.45 and with Hasimoto's dilute limit at 0.064 within 3 %; the mesh study at 0.216 converges towards the reference (-2.0 %, -1.7 %, -1.1 %).

The geometry script

The script periodic_sphere_array_permeability_geometry.py builds the geometry with the CAD objects of OneSimulation and writes the files. Change a dimension there, run it, and run the notebook again.

"""Geometry of the OneSimulation example "Homogenized permeability of a simple cubic sphere packing".

Builds a quarter of the periodic unit cell of a simple cubic array of spheres with the CAD objects
of OneSimulation: the cell has the side 1 mm, the quarter holds the half 1 mm x 0.5 mm x 0.5 mm with
a quarter sphere centred on its edge at (0.5, 0, 0) mm. One file per solid fraction:
periodic_sphere_array_permeability.step (solid fraction 0.216) and
periodic_sphere_array_permeability_<per mille>.step for 64 to 450 per mille. The faces keep their
names x_min, x_max, y_min, y_max, z_min and z_max, the sphere surface is sphere.surface.
"""

import numpy as np
from onesim.cad.d3 import Box, Sphere

side = 1e-3
for per_mille in (64, 125, 216, 343, 450):
    radius = side * (3 * per_mille / 1000 / (4 * np.pi)) ** (1 / 3)
    quarter = Box(length=side, width=side / 2, height=side / 2) - Sphere(
        radius=radius, origin=(side / 2, 0.0, 0.0)
    ).named("sphere")
    quarter.save(f"periodic_sphere_array_permeability_{per_mille}.step")
    if per_mille == 216:
        quarter.save("periodic_sphere_array_permeability.step")

The notebook

The complete notebook, cell by cell. Run it to produce the figures and the comparison printout.

A macroscopic model of a packed bed, a sintered filter or a granular soil treats the pores as a continuum with two properties: the porosity \(\varepsilon\) and the permeability \(K\) of Darcy's law \(\langle\mathbf u\rangle=-(K/\mu)\nabla\langle p\rangle\). Both follow from one periodic cell of the microstructure. Here the cell of side \(L\) holds one sphere of radius \(a\), the solid fraction is \(c=1-\varepsilon=4\pi a^3/(3L^3)\). A uniform pressure gradient \(G\) along \(x\), applied as a body force, drives the creeping flow; then \(K=\mu\langle u\rangle/G\) with the superficial velocity \(\langle u\rangle\), the flow rate per cell cross-section.

Two mirror planes through the sphere centres and two between the spheres cut the cell into quarters, so one quarter is enough. It comes from the CAD files periodic_sphere_array_permeability.step (\(c=0.216\)) and periodic_sphere_array_permeability_64.step to ..._450.step, written by periodic_sphere_array_permeability_geometry.py.

\[-\nabla p+\mu\nabla^2\mathbf u+G\,\mathbf e_x=0,\qquad\nabla\cdot\mathbf u=0\]

| face | condition | |---|---| | x_min / x_max | periodic pair | | y_min, y_max, z_min, z_max (mirror planes) | impermeable, shear free | | sphere.surface | no slip |

Reference. The drag on each sphere, \(F=GL^3\), is usually given relative to Stokes' drag on a single sphere in the superficial velocity, \(K^*=F/(6\pi\mu a\langle u\rangle)\), so that \(K=L^3/(6\pi a K^*)\). A. A. Zick and G. M. Homsy, "Stokes flow through periodic arrays of spheres", J. Fluid Mech. 115, 13-26 (1982), Table 2, simple cubic array: \(K^*=2.810\), 4.292, 7.442, 15.4 and 28.1 for \(c=0.064\), 0.125, 0.216, 0.343 and 0.45. Dilute limit (H. Hasimoto, J. Fluid Mech. 5, 317-328, 1959): \(K^*=1/(1-1.7601\,c^{1/3}+c-1.5593\,c^2)\).

from onesim.cad.exchange import load
from onesim.materials import NewtonianFluid
from onesim.meshing import LocalRefinement, PeriodicPair, TetrahedralMesher
from onesim.numerics import Numerics

from onesim.numerics.linear import SparseDirect
from onesim.numerics.nonlinear import Newton
from onesim.physics.hydrodynamics import (
    FreeSlipLaw,
    IncompressibleNavierStokes,
    NoSlipWall,
    WallShear,
)

from onesim.simulation import PeriodicBoundary, Problem, Simulation

Geometry and mesh

Tetrahedra of a tenth of the cell side, finer on the sphere; the two periodic faces carry the same triangles. The mesh study at \(c=0.216\) adds a coarser and a finer mesh.

fractions = (0.064, 0.125, 0.216, 0.343, 0.450)
zick_homsy = {0.064: 2.810, 0.125: 4.292, 0.216: 7.442, 0.343: 15.4, 0.450: 28.1}
cells = {
    fraction: load(f"periodic_sphere_array_permeability_{round(1000 * fraction)}.step")
    for fraction in fractions
}
side = cells[0.216].size[0]
radius = {
    fraction: side * (3 * fraction / (4 * np.pi)) ** (1 / 3) for fraction in fractions
}
cases = [(fraction, 0.10) for fraction in fractions] + [(0.216, 0.14), (0.216, 0.07)]
meshes = {
    (fraction, size): TetrahedralMesher(
        target_size=size * side,
        refinements=(
            LocalRefinement(
                region=cells[fraction].boundaries["sphere.surface"],
                target_size=0.6 * size * side,
            ),
        ),
        periodic_pairs=(
            PeriodicPair(
                first=cells[fraction].boundaries.x_min,
                second=cells[fraction].boundaries.x_max,
            ),
        ),
    ).generate(cells[fraction])
    for fraction, size in cases
}

cell = load("periodic_sphere_array_permeability.step")
view = plots.Camera(elevation=28, azimuth=-60)
fig = plots.figure(1, 2, size=(14, 6))
plots.geometry(
    cell,
    selection={
        "sphere": cell.boundaries["sphere.surface"],
        "periodic pair": cell.boundaries.x_min | cell.boundaries.x_max,
    },
    labels=False,
    camera=view,
    title="Quarter of the unit cell, c = 0.216",
    ax=fig[0],
)
plots.mesh(
    meshes[0.216, 0.10],
    groups=("all",),
    legend=False,
    camera=view,
    title=f"{meshes[0.216, 0.10].cell_count} tetrahedra",
    ax=fig[1],
)
plots.show()

Model

Water and a pressure gradient of 1 Pa/m keep the Reynolds number far below one. The pressure, periodic and fixed only up to a constant, gets the mean value zero.

water, gradient = NewtonianFluid(density=1000.0, dynamic_viscosity=1.0e-3), 1.0
flows = {}
for fraction, size in cases:
    faces = cells[fraction].boundaries
    model = IncompressibleNavierStokes(
        domain=cells[fraction].volume, material=water, body_force=(gradient, 0.0, 0.0)
    )
    problem = Problem(
        name="Sphere array unit cell",
        geometry=cells[fraction],
        physics=(model,),
        boundary_conditions=(
            NoSlipWall(boundary=faces["sphere.surface"], physics=model),
            WallShear(
                boundary=faces.y_min | faces.y_max | faces.z_min | faces.z_max,
                physics=model,
                law=FreeSlipLaw(),
            ),
            PeriodicBoundary(
                pair=PeriodicPair(first=faces.x_min, second=faces.x_max), physics=model
            ),
        ),
        constraints=(MeanValue(model.pressure, 0.0),),
    )
    numerics = Numerics(
        spatial=FiniteElement(element=TaylorHood()),
        initial_guess={model.velocity: (0.0, 0.0, 0.0)},
        nonlinear_solver=Newton(
            linear_solver=SparseDirect(),
            absolute_tolerance=1e-20,
            relative_tolerance=1e-10,
        ),
    )
    flows[fraction, size] = (
        Simulation(problem=problem, mesh=meshes[fraction, size], numerics=numerics)
        .solve_stationary()
        .field(model.velocity)
    )

Results

The superficial velocity is the flow rate through the quarter divided by its volume times its length; the porosity is the fluid volume over the cell volume. The flat faces of the tetrahedra make the sphere slightly smaller than drawn, which shows in the porosity. Hasimoto's expansion holds only for dilute arrays.

volume = side**3 / 4
porosity = {
    fraction: derived_field(
        flows[fraction, 0.10],
        lambda u, points: np.ones(len(points)),
        name="one",
        unit="1",
    )
    .integrate()
    .value
    / volume
    for fraction in fractions
}
permeability = {
    key: water.dynamic_viscosity * velocity.integrate().value[0] / volume / gradient
    for key, velocity in flows.items()
}
drag = {
    (fraction, size): side**3
    / (6 * np.pi * radius[fraction] * permeability[fraction, size])
    for fraction, size in cases
}
hasimoto = lambda c: 1 / (1 - 1.7601 * c ** (1 / 3) + c - 1.5593 * c**2)

print(
    "  c      porosity  exact    K [m²]        K*      Zick & Homsy   deviation   Hasimoto"
)
for fraction in fractions:
    print(
        f"{fraction:6.3f} {porosity[fraction]:9.4f} {1 - fraction:7.4f} {permeability[fraction, 0.10]:12.4e} {drag[fraction, 0.10]:8.3f}"
        f" {zick_homsy[fraction]:10.3f} {100 * (drag[fraction, 0.10] / zick_homsy[fraction] - 1):+10.1f} %"
        + (f" {hasimoto(fraction):9.3f}" if fraction < 0.15 else "    (dilute only)")
    )
print(
    "\nmesh study at c = 0.216: K* = "
    + ", ".join(
        f"{drag[0.216, size]:.4f} ({meshes[0.216, size].cell_count} tetrahedra)"
        for size in (0.14, 0.10, 0.07)
    )
)

Going further

Shift the sphere into the corners and the face centres of the cell in periodic_sphere_array_permeability_geometry.py to model body-centred and face-centred packings, or let the spheres overlap to model a sintered material. Driving the flow along \(y\) and \(z\) in turn gives the full permeability tensor of an anisotropic cell.
