Rayleigh-Bénard convection: onset of the rolls

A fluid layer heated from below stays at rest until the Rayleigh number passes 1707.8; then two counter-rotating convection rolls carry the heat.

What it computes

OneSimulation couples the steady Navier-Stokes equations (Taylor-Hood) and the heat transport (quadratic elements) both ways through the Boussinesq buoyancy force and solves them by stationary partitioned iteration on the cross-section of a STEP layer one critical wavelength wide. A sweep over the Rayleigh number and a fit through the convecting states locate the onset. The script that builds the STEP file comes with the notebook.

What it checks

The extrapolated critical Rayleigh number is 1703.0 from the Nusselt number and 1708.7 from the roll velocity, -0.28 % and +0.06 % from the linear-stability value 1707.76; below the onset the disturbance decays to Nu = 1.00000, and at Ra = 2500 Nu = 1.4733 lies 0.23 % from Clever and Busse (1.47) and changes by 0.05 % on the finer mesh.

The geometry script

The script rayleigh_benard_convection_onset_geometry.py builds the geometry with the CAD objects of OneSimulation and writes the file. Change a dimension there, run it, and run the notebook again.

"""Geometry of the OneSimulation example "Rayleigh-Benard convection: onset of the rolls".

Builds a horizontal fluid layer of depth 1 (dimensionless units) and width 2*pi/3.117, one
critical wavelength, as a slab 0.1 thick with the CAD objects of OneSimulation and writes
rayleigh_benard_convection_onset.step. The faces are named heated_bottom, cooled_top and sides; the
example computes on the cross-section z = 0.05.
"""

import numpy as np
from onesim.cad.d3 import Box

layer = Box(length=2 * np.pi / 3.117, width=1.0, height=0.1)
layer = layer.grouped(
    heated_bottom=layer.boundaries.y_min,
    cooled_top=layer.boundaries.y_max,
    sides=layer.boundaries.x_min | layer.boundaries.x_max,
)
layer.save("rayleigh_benard_convection_onset.step")

The notebook

The complete notebook, cell by cell. Run it to produce the figures and the comparison printout.

A fluid layer of depth \(d\) lies between two rigid horizontal plates; the lower plate is warmer than the upper one by \(\Delta T\). Warm, light fluid sits under cold, heavy fluid, but viscosity and heat conduction damp every disturbance as long as the Rayleigh number

\[Ra=\frac{g\beta\Delta T\,d^3}{\nu\alpha}\]

stays below the critical value \(Ra_c=1707.76\). Above it the conduction state is unstable and steady two-dimensional rolls of wavelength \(2\pi d/3.117\) appear. The Nusselt number, the heat carried across the layer divided by the conducted heat, grows from 1 linearly in \(Ra-Ra_c\) near the onset.

In units of \(d\), \(\Delta T\) and \(\alpha\) (Prandtl number \(Pr=1\)) the steady Boussinesq equations are solved on a layer one critical wavelength wide. Its side walls are planes of symmetry of the roll pattern (free slip, no heat flux), so two counter-rotating rolls fit exactly; the initial temperature carries a small disturbance of that shape. The layer comes from the CAD file rayleigh_benard_convection_onset.step, written by rayleigh_benard_convection_onset_geometry.py with the CAD objects of OneSimulation.

Reference. Linear stability of the layer between rigid plates: \(Ra_c=1707.76\) at wave number \(a_c=3.117\) (W. H. Reid and D. L. Harris, Phys. Fluids 1, 102 (1958); S. Chandrasekhar, Hydrodynamic and Hydromagnetic Stability, 1961, Ch. II). Steady rolls of the critical wavelength at \(Ra=2500\): \(Nu=1.47\) (R. M. Clever and F. H. Busse, J. Fluid Mech. 65, 625 (1974)).

Geometry and mesh

The cross-section at half thickness keeps the face names. Two meshes: triangles of 1/8 and 1/12 of the layer depth.

part = load("rayleigh_benard_convection_onset.step")
layer = part.section((0, 0, 1), origin=(0, 0, part.size[2] / 2))
faces = layer.boundaries
width = layer.size[0]
meshes = {
    size: TriangularMesher(target_size=size).generate(layer) for size in (1 / 8, 1 / 12)
}

fig = plots.figure(1, 2, size=(14, 5))

Sweep over the Rayleigh number

Flow (Taylor-Hood) and heat (quadratic elements) are coupled both ways: BoussinesqBuoyancy turns the temperature into the body force, the solved velocity carries the heat. StationaryPartitionedCoupling iterates the two stationary solvers to their common fixed point. One Rayleigh number lies below the onset, four above it, on the coarser mesh; \(Ra=2500\) is also solved on the finer mesh.

prandtl = 1.0
fluid = ThermalFluid(
    density=1.0,
    dynamic_viscosity=prandtl,
    thermal_conductivity=1.0,
    specific_heat_capacity=1.0,
    thermal_expansion_coefficient=1.0,
)
flow = IncompressibleNavierStokes(domain=layer.domain(), material=fluid)
heat = ConvectiveHeatTransfer(domain=layer.domain(), material=fluid, velocity=None)
numerics = {
    flow: Numerics(
        spatial=FiniteElement(element=TaylorHood()),
        initial_guess={flow.velocity: (0.0, 0.0)},
        nonlinear_solver=Newton(
            linear_solver=SparseDirect(),
            absolute_tolerance=1e-10,
            relative_tolerance=1e-9,
        ),
    ),
    heat: Numerics(
        spatial=FiniteElement(
            element=Lagrange(order=2), convection=GalerkinAdvection()
        ),
        linear_solver=SparseDirect(),
    ),
}
runs = [(rayleigh, 1 / 8) for rayleigh in (1500.0, 1800.0, 2000.0, 2250.0, 2500.0)] + [
    (2500.0, 1 / 12)
]
results = {}
for rayleigh, size in runs:
    problem = Problem(
        name=f"Rayleigh-Benard layer, Ra = {rayleigh:.0f}",
        geometry=layer,
        physics=(flow, heat),
        boundary_conditions=(
            NoSlipWall(physics=flow, boundary=faces.heated_bottom | faces.cooled_top),
            WallShear(physics=flow, boundary=faces.sides, law=FreeSlipLaw()),
            FixedTemperature(physics=heat, boundary=faces.heated_bottom, value=1.0),
            FixedTemperature(physics=heat, boundary=faces.cooled_top, value=0.0),
            HeatFlux(physics=heat, boundary=faces.sides, value=0.0),
        ),
        constraints=(MeanValue(flow.pressure, 0.0),),
        initial_conditions=(
            InitialValue(
                heat.temperature,
                lambda x, y: 1
                - y
                + 0.05 * np.sin(np.pi * y) * np.cos(2 * np.pi * x / width),
            ),
        ),
        couplings=(
            FieldCoupling(
                source=heat.temperature,
                target=flow.field("body_force"),
                transfer=BoussinesqBuoyancy(
                    gravity=(0, -rayleigh * prandtl), reference_temperature=0.5
                ),
            ),
            FieldCoupling(
                source=flow.velocity,
                target=heat.advecting_velocity,
                transfer=FieldInterpolation(),
            ),
        ),
    )
    results[rayleigh, size] = Simulation(
        problem=problem,
        mesh={flow: meshes[size], heat: meshes[size]},
        numerics=numerics,
        coupling_solver=StationaryPartitionedCoupling(
            stationary_systems=(flow, heat),
            iteration=FixedPoint(
                relative_tolerance=1e-6,
                absolute_tolerance=1e-9,
                maximum_iterations=400,
                relaxation=0.8,
            ),
        ),
    ).solve_stationary()

Onset and heat transfer

The Nusselt number is the heat entering through the bottom per unit width. Near the onset \(Nu-1\) and the square of the roll velocity both grow linearly with \(Ra-Ra_c\); a fit through the convecting states, extrapolated to zero, gives two estimates of the critical Rayleigh number.

probe = np.array(
    [[x, y] for x in np.linspace(0, width, 41) for y in np.linspace(0.05, 0.95, 19)]
)
table = {
    key: (
        -result.field(heat.temperature).boundary_flux(faces.heated_bottom) / width,
        result.field(heat.temperature).boundary_flux(faces.cooled_top) / width,
        np.abs(result.field(flow.velocity).evaluate(probe)).max(),
        len(result.result_set.solver_report["coupling"]["scaled_changes"]),
    )
    for key, result in results.items()
}
print(
    "    Ra   mesh h   Nu (bottom)   Nu (top)   largest velocity [alpha/d]   coupling sweeps"
)
for (rayleigh, size), (bottom, top, speed, sweeps) in table.items():
    print(
        f"{rayleigh:6.0f} {size:8.4f} {bottom:13.5f} {top:10.5f} {speed:28.4f} {sweeps:17d}"
    )
convecting = [rayleigh for rayleigh, size in runs[:-1] if rayleigh > 1707.76]
nusselt_fit = np.polyfit(
    convecting, [table[rayleigh, 1 / 8][0] - 1 for rayleigh in convecting], 2
)
speed_fit = np.polyfit(
    convecting, [table[rayleigh, 1 / 8][2] ** 2 for rayleigh in convecting], 2
)
onsets = {
    name: min(np.roots(fit).real, key=lambda root: abs(root - 1700))
    for name, fit in (("Nu - 1", nusselt_fit), ("velocity²", speed_fit))
}
print(
    f"\nbelow the onset (Ra = 1500): Nu - 1 = {table[1500.0, 1 / 8][0] - 1:.1e}, largest velocity {table[1500.0, 1 / 8][2]:.1e}: "
    f"the disturbance has decayed"
)
for name, onset in onsets.items():
    print(
        f"critical Rayleigh number from {name:9s}: {onset:8.1f}, linear stability 1707.76 ({100 * (onset / 1707.76 - 1):+.2f} %)"
    )
print(
    f"Nusselt number at Ra = 2500: {table[2500.0, 1 / 8][0]:.4f}, Clever & Busse 1.47 ({100 * (table[2500.0, 1 / 8][0] / 1.47 - 1):+.2f} %); "
    f"finer mesh {table[2500.0, 1 / 12][0]:.4f} ({100 * (table[2500.0, 1 / 12][0] / table[2500.0, 1 / 8][0] - 1):+.3f} %)"
)

Going further

Change the width of the layer in rayleigh_benard_convection_onset_geometry.py and the onset moves up along the neutral curve \(Ra(a)\); raise the Rayleigh number further to follow \(Nu(Ra)\) until the rolls become time dependent; or replace the upper plate by a free surface (free slip), for which the critical value drops to 1100.65.
