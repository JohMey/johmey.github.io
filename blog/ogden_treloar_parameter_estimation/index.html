Ogden parameters from Treloar's tests

The six parameters of the three-term Ogden model are estimated from Treloar's tests on natural rubber in uniaxial tension, equibiaxial tension and pure shear.

What it computes

OneSimulation runs the three homogeneous material tests of the incompressible Ogden material for every trial parameter set and fits all 52 measured points with the Levenberg-Marquardt method on their relative deviations; the covariance of the fit gives standard errors for all six parameters.

What it checks

The fit (μ = 365, 0.64, 16.7 kPa; α = 1.55, 5.85, -1.83; initial shear modulus 382 kPa) is of the same character as Ogden's 1972 parameters and lowers the overall relative RMS misfit from 13.6 % to 12.6 % (uniaxial 4.6 %, equibiaxial 14.8 %, pure shear 18.2 %); the standard errors show that the small second and third terms are only weakly determined.

The notebook

The complete notebook, cell by cell. Run it to produce the figures and the comparison printout.

The Ogden model writes the strain energy of rubber directly in the principal stretches,

\[W=\sum_{p=1}^{N}\frac{2\mu_p}{\alpha_p^2}\big(\lambda_1^{\alpha_p}+\lambda_2^{\alpha_p}+\lambda_3^{\alpha_p}-3\big),\qquad \lambda_1\lambda_2\lambda_3=1 ,\]

with the initial shear modulus \(\mu_0=\sum\mu_p\). With three terms it reproduces natural rubber over the whole range of the tests: a soft term with \(\alpha\approx1.3\), a stiffening term with a large exponent and a term with a negative exponent for biaxial states. Six parameters cannot be found from one test; uniaxial tension, equibiaxial tension and pure shear together separate them.

Data. L.R.G. Treloar, Stress-strain data for vulcanised rubber under various types of deformation, Trans. Faraday Soc. 40, 1944, 59-70: 23 points in uniaxial tension, 16 in equibiaxial tension and 13 in pure shear, from a widely used digitisation of the original figures (nominal stress converted from kgf/cm² to Pa). All 52 points enter with their relative deviation.

Reference. R.W. Ogden, Large deformation isotropic elasticity - on the correlation of theory and experiment for incompressible rubberlike solids, Proc. R. Soc. Lond. A 326, 1972, 565-584, fitted the same tests with \(\alpha=(1.3,\,5.0,\,-2.0)\) and, in the convention above, \(\mu\approx(402,\,3.0,\,9.8)\) kPa (his coefficients \(6.3\), \(0.012\), \(-0.1\) kgf/cm² times \(\alpha_p/2\)). The fit must find a set of the same character with a misfit no larger than his.

The material tests

HomogeneousFiniteStrainTest is a single material point under the homogeneous stretch of the chosen mode, with zero traction on the free directions and the incompressibility constraint; a damped Newton method finds the free stretch and the pressure at every point of the curve.

newton = DampedNewton(
    linear_solver=SparseDirect(),
    relative_tolerance=0.0,
    absolute_tolerance=2e-12,
    maximum_iterations=80,
).bind()
tests = lambda mu, alpha, stretches: {
    mode: HomogeneousFiniteStrainTest(
        material=IsochoricOgden(mu=mu, alpha=alpha),
        volume_law=IncompressibleVolumeLaw(),
    ).solve(
        mode=mode,
        stretches=stretches[mode],
        solver=newton,
        linearize=centered_array_jacobian,
        stress_scale=1e6,
    )
    for mode in treloar
}
measured_stretch = {mode: stretch for mode, (stretch, _) in treloar.items()}

The fit

Six parameters, each inside physical bounds; the third term keeps a negative exponent. The study service runs the three tests for every trial set and minimises the relative residuals with the Levenberg-Marquardt method, starting from rounded values.

names = ("mu1", "mu2", "mu3", "alpha1", "alpha2", "alpha3")
study = SimulationStudyService(
    tuple(
        StudyParameter(name, low, high)
        for name, low, high in zip(
            names, (1e5, 1.0, 1.0, 0.5, 3.0, -5.0), (1e6, 2e4, 8e4, 3.0, 9.0, -1.0)
        )
    ),
    build=lambda v: tests(
        (v["mu1"], v["mu2"], v["mu3"]),
        (v["alpha1"], v["alpha2"], v["alpha3"]),
        measured_stretch,
    ),
    solve=lambda results: results,
    measure=lambda results: {
        f"{mode}_{k}": float(value)
        for mode, result in results.items()
        for k, value in enumerate(result.nominal_stress[:, 0, 0])
    },
)
fit = study.fit(
    residuals=lambda values: np.concatenate(
        [
            np.array([values[f"{mode}_{k}"] for k in range(len(stress))]) / stress - 1
            for mode, (_, stress) in treloar.items()
        ]
    ),
    start={
        "mu1": 4e5,
        "mu2": 2e3,
        "mu3": 1e4,
        "alpha1": 1.5,
        "alpha2": 5.0,
        "alpha3": -2.0,
    },
    method="levenberg_marquardt",
    maximum_runs=2000,
)

Comparison with the reference

The fitted parameters with their standard errors beside Ogden's, and the misfit of both parameter sets in each load mode.

fitted = (
    tuple(fit.parameters[n] for n in names[:3]),
    tuple(fit.parameters[n] for n in names[3:]),
)
ogden_1972 = (
    (0.618e6 * 1.3 / 2, 1.18e3 * 5.0 / 2, -9.8e3 * -2.0 / 2),
    (1.3, 5.0, -2.0),
)
print(f"{'':16s}" + "".join(f"{name:>11s}" for name in names))
print(

)
print(
    f"{'standard error':16s}"
    + "".join(

)
print(
    f"{'Ogden (1972)':16s}"
    + "".join(
        f"{value / (1e3 if k < 3 else 1):11.3f}"
        for k, value in enumerate(ogden_1972[0] + ogden_1972[1])
    )
)
print(
    f"initial shear modulus: fit {sum(fitted[0]) / 1e3:.1f} kPa, Ogden (1972) {sum(ogden_1972[0]) / 1e3:.1f} kPa; "
    f"converged: {fit.converged}, rank {fit.rank}, {fit.run_count} parameter evaluations"
)
results = {
    "fit": tests(*fitted, measured_stretch),
    "Ogden (1972)": tests(*ogden_1972, measured_stretch),
}

    f"{'relative RMS deviation':24s}"
    + "".join(f"{mode:>14s}" for mode in treloar)
    + f"{'all 52 points':>15s}"
)
for label, result in results.items():
    deviation = {
        mode: result[mode].nominal_stress[:, 0, 0] / stress - 1
        for mode, (_, stress) in treloar.items()
    }
    print(
        f"{label:24s}"
        + "".join(
            f"{100 * np.sqrt(np.mean(values**2)):13.1f}%"
            for values in deviation.values()
        )
        + f"{100 * np.sqrt(np.mean(np.concatenate(list(deviation.values())) ** 2)):14.1f}%"
    )

The three tests with the fitted model and with Ogden's parameters, evaluated on fine stretch grids, and the relative deviation of the fit from every measured point.

fine = {
