Counterflow heat exchanger (effectiveness-NTU)

Hot and cold streams exchanging heat through a wall, graded against the effectiveness-NTU relations.

What it computes

OneSimulation solves two advection-diffusion channels coupled through a wall conductance by a partitioned fixed-point iteration between the streams. The geometry is read from a STEP file with named faces; the script that builds it comes with the notebook.

What it checks

Outlet temperatures are within about 0.3 % of the inlet difference; the effectiveness and the exponential bulk profiles match the counterflow NTU solution.

Geometry

The notebook starts at the import of the CAD file counterflow_heat_exchanger_ntu.step: STEP (AP242), readable by any CAD program, with the names of the faces that the boundary conditions use. Put it next to the notebook.

"""Geometry of the OneSimulation example "Counterflow heat exchanger".

Builds one channel of the exchanger, 45 mm long with a 1 mm gap (along y) and 2 mm width (along z),
with the CAD objects of OneSimulation and writes counterflow_heat_exchanger_ntu.step. Both streams
use this channel. The faces keep their names x_min, x_max, y_min, y_max, z_min and z_max in the
file; the two faces across the width form the group ends.
"""

from onesim.cad.d3 import Box

duct = Box(length=0.045, width=1.0e-3, height=2.0e-3)
faces = duct.boundaries
duct = duct.grouped(ends=faces.z_min | faces.z_max)
duct.save("counterflow_heat_exchanger_ntu.step")

The notebook

The complete notebook, cell by cell. Run it to produce the figures and the comparison printout.

Two water streams flow in opposite directions through parallel channels (1 mm gap, 2 mm wide, 45 mm long) separated by a 1.2 mm polypropylene wall. Heat crosses the wall from the hot to the cold stream; the outer faces are insulated. Each channel obeys

\[\rho c_p\,\mathbf u\cdot\nabla T=k\,\nabla^2 T ,\]

and exchanges the heat flux \(h_w\,(T_h-T_c)\) with the other one through the wall conductance \(h_w=k_w/t_w\).

Both streams use the channel from the CAD file counterflow_heat_exchanger_ntu.step with the faces x_min and x_max (the two ends), y_min and y_max (across the gap) and the group ends across the width. The script counterflow_heat_exchanger_ntu_geometry.py builds it with the CAD objects of OneSimulation.

Reference. With the capacity rates \(C=\rho c_p u\,t\,w\) of the two streams, \(C_r=C_\min/C_\max\) and \(\mathrm{NTU}=UA/C_\min\), the effectiveness of a counterflow exchanger is

\[\varepsilon=\frac{1-e^{-\mathrm{NTU}(1-C_r)}}{1-C_r\,e^{-\mathrm{NTU}(1-C_r)}} ,\]

and the temperature difference between the streams decays as \(e^{-mx}\) with \(m=Uw\,(1/C_h-1/C_c)\). The overall coefficient combines the wall with the two fluid films, \(1/U=t_w/k_w+2t/(3k_f)\).

Model

solve computes one stream for a given wall temperature of the other stream. The two streams are solved in turn until the temperatures settle.

water = IsotropicSolid(
    density=1000.0,
    specific_heat_capacity=4180.0,
    thermal_conductivity=0.6,
    youngs_modulus=2e9,
    poisson_ratio=0.3,
    thermal_expansion_coefficient=1e-5,
)
wall_conductance = 0.12 / 1.2e-3
hot_inlet, cold_inlet, ntu, capacity_ratio = 350.0, 290.0, 1.5, 0.6
overall = 1 / (1 / wall_conductance + 2 * gap / (3 * water.thermal_conductivity))
hot_capacity = overall * length * width / ntu
cold_capacity = hot_capacity / capacity_ratio
speed = lambda capacity: capacity / (
    water.density * water.specific_heat_capacity * gap * width
)
numerics = Numerics(
    spatial=FiniteElement(element=Lagrange(order=2), convection=GalerkinAdvection()),
    linear_solver=SparseDirect(),
)


def solve(velocity, inlet, outlet, wall, outer, inlet_temperature, other_stream):
    """Temperature of one stream; `other_stream(x)` is the wall temperature of the other one."""
    model = ConvectiveHeatTransfer(
        domain=duct.volume, material=water, velocity=(velocity, 0.0, 0.0)
    )
    problem = Problem(
        name="Exchanger channel",
        geometry=duct,
        physics=(model,),
        boundary_conditions=(
            FixedTemperature(boundary=inlet, physics=model, value=inlet_temperature),
            HeatFlux(boundary=outlet | outer | faces.ends, physics=model, value=0.0),
            ConvectiveHeatFlux(
                boundary=wall,
                physics=model,
                heat_transfer_coefficient=wall_conductance,
                ambient_temperature=other_stream,
            ),
        ),
    )
    return (
        Simulation(problem=problem, mesh=mesh, numerics=numerics)
        .solve_stationary()
        .field(model.temperature)
    )


def at_wall(field, y):
    """Temperature of a stream on its wall face as a function of x."""
    return lambda x: field.evaluate(
        np.column_stack(
            (np.ravel(x), np.full(np.size(x), y), np.full(np.size(x), width / 2))
        )
    ).reshape(np.shape(x))


cold_wall = lambda x: cold_inlet + 0.0 * np.asarray(x)
for sweep in range(12):
    hot = solve(
        speed(hot_capacity),
        faces.x_min,
        faces.x_max,
        faces.y_max,
        faces.y_min,
        hot_inlet,
        cold_wall,
    )
    cold = solve(
        -speed(cold_capacity),
        faces.x_max,
        faces.x_min,
        faces.y_min,
        faces.y_max,
        cold_inlet,
        at_wall(hot, gap),
    )
    cold_wall = at_wall(cold, 0.0)

Results

The bulk temperature of each stream is its mean over the channel cross-section. The effectiveness-NTU solution gives the heat flow, the decay rate \(m\) and from them both bulk temperatures along the exchanger.

x = length * np.linspace(1e-6, 1 - 1e-6, 31)
hot_bulk, cold_bulk = (
    np.array(
        [
            mean_value(field, plane=Plane(origin=(position, 0, 0), normal=(1, 0, 0)))
            for position in x
        ]
    )
    for field in (hot, cold)
)
decay = np.exp(-ntu * (1 - capacity_ratio))
effectiveness = (1 - decay) / (1 - capacity_ratio * decay)
m = overall * width * (1 / hot_capacity - 1 / cold_capacity)
difference = (
    hot_inlet
    - cold_inlet
    - effectiveness * hot_capacity / cold_capacity * (hot_inlet - cold_inlet)
)
hot_exact = (
    hot_inlet - overall * width / hot_capacity * difference * (1 - np.exp(-m * x)) / m
)
cold_exact = hot_exact - difference * np.exp(-m * x)
power = hot_capacity * (hot_inlet - hot_bulk[-1])

print(
    f"hot outlet    simulation {hot_bulk[-1]:.2f} K   effectiveness-NTU {hot_exact[-1]:.2f} K"
)
print(
    f"cold outlet   simulation {cold_bulk[0]:.2f} K   effectiveness-NTU {cold_exact[0]:.2f} K"
)
print(
    f"effectiveness simulation {power / (hot_capacity * (hot_inlet - cold_inlet)):.4f}     effectiveness-NTU {effectiveness:.4f}"
)
print(
    f"heat given off by the hot stream {power:.4f} W, taken up by the cold stream "
    f"{cold_capacity * (cold_bulk[0] - cold_inlet):.4f} W"
)

Going further

Make the two capacity rates equal: the temperature difference is then uniform and both profiles become straight lines. Reverse the cold stream to obtain a parallel-flow exchanger, whose effectiveness is lower at the same NTU. Lengthen the channel in counterflow_heat_exchanger_ntu_geometry.py and write the STEP file again to raise the NTU.
