Diffusion-reaction in a catalyst slab

What it computes

OneSimulation solves steady diffusion with a first-order reaction on a slab with a reservoir face and a sealed centre.

What it checks

The profile cosh(phi(1-x/L))/cosh(phi) and the effectiveness factor tanh(phi)/phi match the closed form.

The notebook

The complete notebook, cell by cell. Run it to produce the figures and the comparison printout.

A reactant diffuses into a flat porous catalyst slab and is consumed there by a first-order surface reaction. The slab has half-thickness \(L\): its open face at \(x=0\) is held at the external concentration \(C_s\), and its centre plane (or sealed back) at \(x=L\) carries no flux by symmetry. With diffusivity \(D\), rate coefficient \(k\) and no convection the steady balance is

\[D\,\frac{d^2C}{dx^2}=k\,C,\qquad C(0)=C_s,\quad \left.\frac{dC}{dx}\right|_{x=L}=0.\]

OneSimulation integrates the transient species balance in time on a real 1D line mesh with continuous finite elements (Lagrange order 2, surface value enforced weakly with Nitsche) until only the steady profile remains.

Reference. Introducing the dimensionless Thiele modulus \(\phi=L\sqrt{k/D}\), the linear constant-coefficient ODE with a sealed back has the exact solution

\[\frac{C(x)}{C_s}=\frac{\cosh\!\big(\phi\,(1-x/L)\big)}{\cosh\phi}.\]

The effectiveness factor — the actual conversion divided by the conversion the slab would reach at the surface concentration everywhere — follows as

\[\eta=\frac{1}{L\,C_s}\int_0^L C\,dx=\frac{\tanh\phi}{\phi}.\]

We compare the computed steady profile and effectiveness factor with these closed forms.

import numpy as np
from onesim.cad.d1 import Line
from onesim.meshing import StructuredLineMesher
from onesim.numerics import Numerics
from onesim.numerics.fem import FiniteElement, Lagrange, Nitsche
from onesim.numerics.linear import SparseDirect
from onesim.numerics.nonlinear import Newton
from onesim.numerics.time import BDF, BackwardEuler
from onesim.physics.chemistry import SpeciesTransport, TransportSpecies
from onesim.simulation import (
    OutwardFluxBoundary,
    PrescribedValueBoundary,
    Problem,
    Simulation,
)
from onesim.simulation.initial_conditions import InitialValue
from onesim.visualization import plots, theme

theme.set()

Parameters

The values are freely adjustable and in SI units. They give a moderate Thiele modulus \(\phi=2\), where diffusion limits the reaction appreciably but the interior is not fully starved.

L = 1.0
cells = 200
D = 0.1
k = 0.4
C_s = 1.0

phi = L * np.sqrt(k / D)
eta_ref = np.tanh(phi) / phi
print(f"Thiele modulus phi = {phi:.3f},  analytic effectiveness eta = {eta_ref:.4f}")


def reference(x):
    return C_s * np.cosh(phi * (1.0 - x / L)) / np.cosh(phi)


line = Line(start=(0.0, 0.0, 0.0), end=(L, 0.0, 0.0))
mesh = StructuredLineMesher(cells=cells).generate(line)
print("Mesh:", mesh.cell_count, "line cells")

species = (TransportSpecies("reactant", diffusivity=D, decay_rate=k),)
model = SpeciesTransport(domain=line.line, velocity=0.0, species=species)

Both ends carry an explicit boundary condition: the surface concentration is prescribed at the open face, and the sealed centre plane carries zero flux.

boundary_conditions = (
    PrescribedValueBoundary(
        physics=model,
        boundary=line.boundaries.start,
        value=lambda time, coordinate: {"reactant": C_s},
    ),
    OutwardFluxBoundary(
        physics=model,
        boundary=line.boundaries.end,
        flux=lambda **kw: np.zeros(1),
        jacobian=lambda **kw: np.zeros((1, 1)),
    ),
)

problem = Problem(
    name="steady reaction-diffusion in a catalyst slab",
    geometry=line,
    physics=(model,),
    boundary_conditions=boundary_conditions,
    initial_conditions=(InitialValue(model.concentration("reactant"), 0.0),),
)

The slowest transient mode decays at a rate of order D (pi/2L)^2 + k, so a few tens of those times are enough to settle onto the steady profile.

settling_rate = D * (np.pi / (2.0 * L)) ** 2 + k
end_time = 40.0 / settling_rate
time_step = end_time / 400.0
print(f"settling run: end time = {end_time:.1f} s,  time step = {time_step:.3f} s")

result = Simulation(
    problem=problem,
    mesh=mesh,
    numerics=Numerics(
        spatial=FiniteElement(
            element=Lagrange(2), quadrature_order=5, boundary_enforcement=Nitsche()
        ),
        linear_solver=SparseDirect(),
        nonlinear_solver=Newton(
            linear_solver=SparseDirect(),
            jacobian="analytic",
            absolute_tolerance=1e-12,
            relative_tolerance=1e-11,
        ),
        time_integrator=BDF(order=2, startup=BackwardEuler()),
    ),
).run(start_time=0.0, end_time=end_time, time_step=time_step)

Comparison with the closed-form steady profile

The last stored time is deep in the steady regime. We compare the computed concentration with the exact hyperbolic-cosine profile.

field = result.field(model.concentration("reactant"))
points = np.asarray(field.space.dof_coordinates)
x = points[:, 0]
order = np.argsort(x)
x = x[order]
c_num = np.asarray(field.evaluate(points, time=float(result.times[-1]))).reshape(-1)[
    order
]

c_ref = reference(x)
max_abs_error = float(np.max(np.abs(c_num - c_ref)))
rel_error = max_abs_error / C_s
print(
    f"maximum deviation from the closed form: {max_abs_error:.3e} mol/m^3  ({100*rel_error:.3f} % of C_s)"
)

previous = np.asarray(field.evaluate(points, time=float(result.times[-2]))).reshape(-1)[
    order
]
drift = float(np.max(np.abs(c_num - previous)))
print(f"change over the last stored interval: {drift:.3e} mol/m^3")

Effectiveness factor

The effectiveness factor is the slab-averaged concentration divided by C_s. We integrate the computed profile with the trapezoidal rule and compare with the analytic tanh(phi)/phi.

eta_num = float(np.trapezoid(c_num, x) / (L * C_s))
eta_err = abs(eta_num - eta_ref)
print(
    f"effectiveness factor: numeric {eta_num:.4f}, analytic {eta_ref:.4f}, error {eta_err:.3e}"
)

Figure

xs = np.linspace(0.0, L, 400)
plots.line(
    points={"OneSimulation": (x[::5], c_num[::5])},
    reference={"closed form": (xs, reference(xs))},
    xlabel="position x [m]",
    ylabel="concentration [mol/m^3]",
    title=f"Catalyst slab (Thiele phi = {phi:.1f}, eta = {eta_ref:.3f})",
)
plots.show()

Going further

Raise the rate coefficient \(k\) (larger Thiele modulus) and the reactant is consumed in a thin skin near the open face, so the effectiveness factor falls toward the strong-diffusion-limit \(\eta\approx1/\phi\). Lower \(k\) (small \(\phi\)) and the slab fills almost uniformly with \(\eta\to1\), the reaction-limited regime.
