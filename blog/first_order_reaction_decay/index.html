First-order reaction decay

What it computes

OneSimulation integrates a homogeneous (0D) mass-action network in time with an explicit Runge-Kutta step.

What it checks

Compared with C_A = C_A0 e^(-kt) and C_B = C_A0 (1 - e^(-kt)); within about 1e-8, with mass conserved.

The notebook

The complete notebook, cell by cell. Run it to produce the figures and the comparison printout.

A single species \(A\) decays irreversibly into a product \(B\) in a homogeneous, well-mixed (0D) batch reactor:

\[A \xrightarrow{\;k\;} B .\]

With a first-order (mass-action) rate law the reaction rate is \(r=k\,C_A\), so the concentrations obey

\[\frac{dC_A}{dt}=-k\,C_A,\qquad \frac{dC_B}{dt}=+k\,C_A,\qquad C_A(0)=C_{A0},\;\; C_B(0)=0 .\]

OneSimulation integrates the homogeneous species balance on a lumped (0D) domain with an explicit classical Runge-Kutta scheme; the rate coefficient is declared as a constant mass-action law in a reaction network.

Reference. The linear system has the exact solution

\[C_A(t)=C_{A0}\,e^{-k t},\qquad C_B(t)=C_{A0}\,\bigl(1-e^{-k t}\bigr),\]

and total mass is conserved, \(C_A(t)+C_B(t)=C_{A0}\). We compare the computed transient with this exponential.

import numpy as np
from onesim.cad.geometry import LumpedDomain
from onesim.meshing import LumpedMesh
from onesim.numerics import Numerics
from onesim.numerics.discretization import LumpedParameters
from onesim.numerics.time import ClassicalRungeKutta4
from onesim.physics.chemistry import (
    ReactionIR,
    ReactionKinetics,
    ReactionNetworkIR,
    SpeciesIR,
)
from onesim.simulation import Problem, Simulation
from onesim.simulation.initial_conditions import InitialValue
from onesim.visualization import plots, theme

theme.set()

Parameters

The values are freely adjustable. The rate coefficient \(k\) sets the characteristic time \(1/k\); the window spans five of those times, so \(A\) decays to about \(e^{-5}\approx0.7\,\%\) of its initial value.

k = 0.8
C_A0 = 1.0
C_B0 = 0.0
tau = 1.0 / k
end_time = 5.0 * tau
time_step = 0.05 * tau
print(
    f"k = {k:.3f} 1/s,  characteristic time 1/k = {tau:.2f} s,  end time = {end_time:.2f} s"
)

Model

Two species (\(A\), \(B\)) and one irreversible reaction \(A\to B\) with a constant (mass-action) rate coefficient. The reactor is a single lumped control volume.

network = ReactionNetworkIR(
    "first_order_decay",
    "1",
    species=(
        SpeciesIR("A", 0, 1e-27, composition={"H": 1}),
        SpeciesIR("B", 0, 1e-27, composition={"H": 1}),
    ),
    reactions=(
        ReactionIR("decay", {"A": 1}, {"B": 1}, {"kind": "constant", "value": k}),
    ),
    strict_balance=True,
)

domain = LumpedDomain()
model = ReactionKinetics(domain=domain.system, temperature=300.0, network=network)
C_A = model.concentration("A")
C_B = model.concentration("B")

problem = Problem(
    name="First-order reaction decay",
    geometry=domain,
    physics=(model,),
    initial_conditions=(
        InitialValue(C_A, C_A0),
        InitialValue(C_B, C_B0),
    ),
)
simulation = Simulation(
    problem=problem,
    mesh=LumpedMesh(domain),
    numerics=Numerics(
        spatial=LumpedParameters(),
        time_integrator=ClassicalRungeKutta4(),
    ),
)
simulation.validate().require_valid()
result = simulation.run(start_time=0.0, end_time=end_time, time_step=time_step)

Comparison with the exponential solution

The stored history of each concentration is read back and compared, time by time, with the closed-form exponential.

times, num_A = result.field(C_A).time_series()
_, num_B = result.field(C_B).time_series()

exact_A = C_A0 * np.exp(-k * times)
exact_B = C_A0 * (1.0 - np.exp(-k * times))

err_A = float(np.max(np.abs(num_A - exact_A)))
err_B = float(np.max(np.abs(num_B - exact_B)))
rel_error = max(err_A, err_B) / C_A0
print(
    f"Maximum absolute error against the exponential: {max(err_A, err_B):.3e} mol/m^3"
    f"  ({100 * rel_error:.4f} % of C_A0)"
)

mass_error = float(np.max(np.abs(num_A + num_B - C_A0)))
print(f"Maximum mass-balance error C_A+C_B-C_A0: {mass_error:.3e} mol/m^3")

Figure

t_fine = np.linspace(0.0, end_time, 400)
shown = slice(None, None, max(1, len(times) // 40))
plots.line(
    points={"C_A": (times[shown], num_A[shown]), "C_B": (times[shown], num_B[shown])},
    reference={
        "C_A": (t_fine, C_A0 * np.exp(-k * t_fine)),
        "C_B": (t_fine, C_A0 * (1.0 - np.exp(-k * t_fine))),
    },
    xlabel="time [s]",
    ylabel="concentration [mol/m^3]",
    title="First-order decay: OneSimulation (markers) and exact solution (dashed)",
)
plots.show()

Going further

Lower the time step and watch the Runge-Kutta error against the exponential shrink at fourth order. Replace the constant rate law by an Arrhenius law ({"kind": "arrhenius", ...}) and couple a temperature so the rate coefficient follows \(k(T)\), or add a reverse reaction \(B\to A\) to obtain a relaxation to chemical equilibrium instead of a complete conversion.
