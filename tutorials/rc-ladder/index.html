A stiff RC ladder: one circuit, every time integrator and solver

A resistor-capacitor ladder charged through a voltage step is declared once as a circuit and advanced with every time integrator, every implicit integrator with every nonlinear solver, and every pair of nonlinear and linear solvers. The number of stages sets the stiffness; explicit methods that cannot be stable at the common step are shown with their stable-step counterpart. Every run is graded against the exact modal solution of the ladder. 299 runs on the compiled OneSimulation runtime: 229 ran as declared, 70 failed as the mathematics predicts and are shown hatched (70 with a stabilized counterpart behind the hatching), none was refused by the library.

A voltage source of \(U=1\,\mathrm{V}\) is switched onto a ladder of \(N\) equal stages: a series resistor \(R=R_\mathrm{tot}/N\) followed by a capacitor \(C=C_\mathrm{tot}/N\) to ground. The far end is open. With the capacitor voltages \(v_1,\dots,v_N\) and \(v_0=U\), Kirchhoff's current law gives

\[RC\,\dot v_i=v_{i-1}-2v_i+v_{i+1}\quad(i<N),\qquad RC\,\dot v_N=v_{N-1}-v_N .\]

For growing \(N\) the ladder approaches a diffusion line (an RC transmission line): the slowest time constant stays near \(4R_\mathrm{tot}C_\mathrm{tot}/\pi^2\) while the fastest shrinks like \(R_\mathrm{tot}C_\mathrm{tot}/(4N^2)\). The ratio of the two is the stiffness that explicit methods must resolve and implicit methods may step over.

Reference. The matrix is symmetric and tridiagonal; its eigenpairs are known in closed form. With \(\vartheta_k=(2k-1)\pi/(2N+1)\) the decay rates are \(\lambda_k=(2-2\cos\vartheta_k)/(RC)\) and the modes \(\phi_k(i)=\sin(i\vartheta_k)\), so

\[v_N(t)=U\Big(1-\sum_{k=1}^{N}c_k\sin(N\vartheta_k)\,e^{-\lambda_k t}\Big),\qquad c_k=\frac{\sum_i\sin(i\vartheta_k)}{\sum_i\sin^2(i\vartheta_k)}\]

(e.g. G. Strang, Introduction to Applied Mathematics, §1.5 on second-difference matrices).

Grading. The far-end voltage \(v_N\) is compared with the exact value at every accepted step; the error is the largest deviation over the run in volts. By the maximum principle every exact voltage stays between 0 and 1 V; a run that leaves \([-0.5, 1.5]\,\mathrm{V}\) has become unstable and is recorded as failed.

Resolution. A circuit has no spatial mesh: LumpedMesh carries all unknowns on one global node; the ladders below have 4, 16 and 32 capacitor states. The resolution is the time step; a step check at half the step closes the notebook.

The physics, declared once

\(R_\mathrm{tot}=1\,\mathrm{k\Omega}\) and \(C_\mathrm{tot}=1\,\mathrm{mF}\), so \(R_\mathrm{tot}C_\mathrm{tot}=1\,\mathrm{s}\). The same circuit declaration with 4, 16 and 32 stages forms the columns of the integrator matrix. Circuit.as_model turns each network into a lumped model whose consistent initial state (all capacitors empty, source on) comes from initial_values.

supply, total_resistance, total_capacitance, end_time, step = 1.0, 1e3, 1e-3, 1.0, 1e-2
sizes = (4, 16, 32)
domain = LumpedDomain()
ladders = {
    n: Circuit(
        components=(CircuitVoltageSource(name="U", positive="n0", negative="0", voltage=supply),)
        + tuple(
            element
            for i in range(n)
            for element in (
                CircuitResistor(
                    name=f"R{i}", positive=f"n{i}", negative=f"n{i + 1}", resistance=total_resistance / n
                ),
                CircuitCapacitor(
                    name=f"C{i}",
                    positive=f"n{i + 1}",
                    negative="0",
                    capacitance=total_capacitance / n,
                    initial_voltage=0.0,
                ),
            )
        )
    ).as_model(domain=domain.system)
    for n in sizes
}
problems = {
    n: Problem(
        name=f"RC ladder with {n} stages",
        geometry=domain,
        physics=(model,),
        initial_conditions=model.initial_values(),
    )
    for n, model in ladders.items()
}
mesh = LumpedMesh(domain)

The exact modal solution

Decay rates, mode shapes and modal coefficients of each ladder, straight from the formulas above.

The method catalogue

Every time integrator of the library that applies to a first-order network. Implicit stages take Newton's method with a sparse direct solve; Rosenbrock stages take the sparse direct solve alone. The nonlinear and linear solvers are varied on their own further below.

Schemes that must fail, and their stabilized counterparts

An explicit method is stable only while \(\lambda_\max\Delta t\) stays inside its stability interval on the negative real axis (2 for forward Euler and the second-order Runge-Kutta methods, about 2.8 for RK4, 1 for Adams-Bashforth 2). At the common step \(\Delta t=10^{-2}\,\mathrm{s}\) that holds for the 4-stage ladder but not for 16 or 32 stages. Adams-Moulton 3 and 4 have bounded stability intervals too, and a fixed-point (Picard) iteration contracts only while \(\lambda_\max\Delta t<1\). Leapfrog is unstable on any decaying mode. A failed cell is hatched; its colour and value are those of the counterpart: the same method at the stable step \(\Delta t_s=0.5/\lambda_\max\); for leapfrog the Robert-Asselin-Williams filtered leapfrog, which is stable only for \(\lambda\Delta t<0.395\), at \(0.3/\lambda_\max\); for the fixed-point iteration a step at which it contracts by a factor of ten per iteration, \(0.1/\lambda_\max\).

The test matrix

1. Time integrator × ladder size — every integrator on 4, 16 and 32 stages at \(\Delta t=10^{-2}\,\mathrm{s}\). 2. Implicit integrator × nonlinear solver — 16 stages, sparse direct linear solves. 3. Nonlinear × linear solver — backward Euler on 32 stages, plus the Rosenbrock-Euler step, which needs only a linear solver. 4. Step check — representative implicit integrators on 16 stages at half the step.

Run everything

One loop, the same problem objects every time. A refused combination is recorded with the library's message; a run that becomes unstable is recorded as failed, and the loop appends its stabilized counterpart, which runs in the same loop.

Every matrix below shows the declared combination. Where it failed and the counterpart ran, the cell is hatched and shows the counterpart; the legend names it.

Implicit integrators on 16 stages at half the step. The error ratio shows the observed order: about 4 for a second-order method, 2 for a first-order one. Crank-Nicolson and implicit midpoint can show less while the undamped fast modes dominate the error.

Methods that do not apply to an RC network

The staggered (velocity) Verlet and symplectic Euler steps need a second-order system, positions whose rate is a velocity; capacitor charges are first-order storage states, and the library refuses both with that reason. Conjugate gradients and algebraic multigrid need a declared symmetric positive definite stage matrix; the reduced nodal storage operator \(-C^{-1}G\) of a general network is only similar to a symmetric one, so the circuit model declares no such property and the library refuses CG with that reason. JFNK never forms the Jacobian, so it has no matrix for a sparse direct (or automatic, which selects the direct) inner solve; it is paired with the Krylov solvers only. A circuit has no spatial discretization, so there is no space axis and no mesh refinement; the step check takes its place. Runge-Kutta-Chebyshev and -Legendre super-steps and IMEX splits are offered for spatial operators that publish a parabolic spectrum or a stiff/non-stiff split, which the circuit model does not.

Going further

Add an inductor to each stage for an LC transmission line, or a diode at the far end for a nonlinear load; the matrix code stays as it is.
