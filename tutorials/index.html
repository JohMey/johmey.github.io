Download and setup

Start with the installation tutorial. It covers downloading a wheel from Gumroad, checking CPython 3.13, creating a virtual environment, installing dependencies and activating the licence on macOS, Ubuntu and Windows.

For an interactive workflow, follow the Jupyter setup and verify that the selected kernel imports onesim from the environment you installed.

Build and run a model

Start with a body cooling by radiation or a damped oscillator. Both have an analytical time history. They let you learn how to specify the physical model and make a unit-aware check before dealing with a spatial mesh.

For a spatial problem, follow the conduction, diffusion and flow studies or import a 3D STEP sleeve and apply a tensile load. The 3D example index includes models with several materials, boundary patches and coupled fields.

In each case the workflow is:

  1. Geometry and regions. Select the volume, faces and named boundaries that the physical model acts on.
  2. Physics and data. Specify material properties, state variables, loads and boundary or initial conditions in a Problem.
  3. Mesh and method. Choose a mesh suited to the geometry and a numerical method suited to the equations.
  4. Execution. Build Simulation with the problem, mesh and Numerics, then choose the stationary or transient solve used in the worked example.
  5. Reference. Extract fields or time histories and check them against an analytical solution, a balance or a published benchmark.

Read and verify results

Read fields, make plots and export results. A field probe, a boundary integral and a time history answer different questions. Choose which one measures your physical quantity before plotting.

Diagnose a suspect result by checking material units and boundary assignments first. Change one numerical input at a time and record the observable used for comparison.

Change the numerical method

  • Choose spatial discretizations and operators for the geometry and governing equation.
  • Compare five methods for a manufactured Poisson problem.
  • Configure linear and nonlinear solvers, time integration and coupled fields.
  • Define and solve your own equation using a reference solution to check the discretization.

The 14-week numerical methods lab and its eight computational exercises extend these comparisons to meshes, solvers and time integrators.

Use the notebook blog for a worked case in your field, then keep its verification check as you change the data. The course notes derive the reference equations and offer follow-on exercises.
