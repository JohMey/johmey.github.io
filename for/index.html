Who OneSimulation is for

OneSimulation is for everyone who simulates: students, teachers, researchers, engineering offices and product teams. Each page below joins the material, the examples and the plan for one of them.

Find your starting point

  • Students

    Lecture notes with the equations, exercises with worked solutions and examples whose exact answer is known. Change a mesh, a scheme or a time step and see what it does to the error.

    Plan: Education, free

  • Teaching

    A complete lab schedule, exercises with deliverables and examples graded against an exact solution. Students run the same library as research and industry users.

    Plan: Education, free

  • Research

    Physics, discretization, time integrator and solver are separate Python objects. Keep the model, swap the method, and grade every run against a reference.

    Plan: Personal & Research, €19 per month

  • Engineering offices

    Import the part, set loads and materials in Python, and deliver figures, fields and a comparison with a reference. Every study is a script you can rerun for the next variant.

    Plan: Focus, €39 per month

  • Companies

    Every part of OneSimulation is a Python API, so studies run from scripts, pipelines and your own applications. The included MCP server lets Codex and Claude Code build, run and read them on your machines.

    Plan: Professional, €79 per month
