A speed regulator with an unknown load and a measured delay

A motor must reject sudden torque changes and track a smooth speed request over a delayed feedback connection. Select nominal integral gains from a time-domain requirement, calculate the delay margin for the actual PI loop and separate reference feedforward from feedback stability.

Problem sheet 7 · Integrative project

1 · Recover from a load with a bounded speed excursion2 · Calculate the margin of this actual loop3 · Predict feedforward torque during a smooth transition4 · Interpret a measured commissioning delay

1 · Recover from a load with a bounded speed excursion

The motor obeys \(J\dot y+by=u-d\) with \(J=0.20\) kg m² and \(b=0.50\) N m s/rad. Use \(u=K_p(r-y)+K_i z,\ \dot z=r-y\). A 2 N m step load should cause a nominal peak error below 1.0 rad/s. Place both undelayed closed-loop poles at −4 s⁻¹. Find the gains and peak.

Check the pole choice against the performance requirement

The characteristic polynomial is \(Js^2+(b+K_p)s+K_i=J(s+4)^2\), so \(K_p=1.10,\ K_i=3.20\) in SI units. At constant reference the step load gives \(y=-10te^{-4t}\) in deviation coordinates. Its largest magnitude is \(10/(4e)=0.920\) rad/s at 0.25 s, meeting the undelayed specification. The controller must retain 2 N m extra torque after recovery. Saturation can invalidate this nominal transient.

Recover the peak excursion and compare proportional-only regulation

2 · Calculate the margin of this actual loop

The entire feedback command is delayed by \(\tau\). Before adding delay, the loop transfer function is \(L_0(s)=(K_ps+K_i)/[s(Js+b)]\). Obtain its positive gain-crossover frequency by equating squared magnitudes. Calculate the first critical delay and the largest delay retaining at least 45° phase margin.

Use the PI zero, integrator and motor pole together

Write \(z=\omega^2\). Unit gain requires

\[J^2z^2+(b^2-K_p^2)z-K_i^2=0.\]

With the chosen values the positive root is \(z=32\), giving \(\omega_c=5.657\) rad/s. Undelayed phase is \(\arctan(K_p\omega_c/K_i)-\pi/2-\arctan(J\omega_c/b)\), giving margin 86.63°. The first critical delay is therefore

\[1.512/5.657=0.267\,\mathrm{s}.\]

A 45° reserve permits about 0.128 s. The separate delay experiment uses a first-order proportional loop. Check there that pure delay changes phase by \(-\omega\tau\), then apply that relation here at the PI loop's own crossover.

Test the linear relation between phase loss and delay

3 · Predict feedforward torque during a smooth transition

Command 0 to 4 rad/s in 1 s with \(r=4(3s^2-2s^3)\), where \(s=t/(1\ {\rm s})\). Add \(u_{\rm ff}=\widehat J\dot r+\widehat b r\). Determine nominal feedforward torque at midpoint and hold. What mismatch appears at midpoint if the estimate is \(\widehat J=0.15\) while drag is correct?

Calculate required and modeled input at the same time

Midpoint speed is 2 rad/s and acceleration is 6 rad/s². The nominal torque is \(0.20(6)+0.50(2)=2.20\) N m. During the final hold it is 2.00 N m. With the low inertia estimate the midpoint command is 1.90 N m, leaving a 0.30 N m shortfall for the feedback loop. The pure reference path changes tracking forcing while leaving the nominal feedback characteristic equation unchanged when signals sum linearly and actuators stay unsaturated.

Set the estimated inertia to 0.15 and 0.20 kg m² during the same move

4 · Interpret a measured commissioning delay

Timing measurements give a repeatable delay of 0.100 s. Calculate the remaining nominal phase margin and the spare latency compatible with the 45° reserve. Can the undelayed 0.920 rad/s load peak now be reported as the delayed result?

Separate the frequency and transient checks

The delay costs \(5.657(0.100)=0.566\) rad or 32.4°, leaving about 54.2°. The spare latency is roughly 0.028 s. The delayed system has a transcendental characteristic equation, so the repeated real poles and analytic load transient of the zero-delay model no longer describe its exact step. A disturbance step experiment or an integration retaining the delay is needed to check the peak requirement at this operating point.
