Change an input, run the Python cells and compare the result with the derivation. You can also download each notebook for Jupyter.

  • Why one sample of latency can change the stability margin

    The controller samples a first-order plant and holds its command until the next sample. Compare immediate application with the same calculation arriving exactly one sample late. Predict which gain produces oscillation before running the notebook.

    Open editable notebook · Download .ipynb · Chapter 6 · Sampling, saturation and commissioning

  • Learn a repeatable positioning move from its previous error

    An inspection stage follows the same position command on hundreds of nominally identical passes. A small force disturbance returns at the same part of each move. The complete tracking record from the previous pass is available before the next move begins. Derive a learning update that uses the stage dynamics to turn that record into a new feedforward command. Its convergence can be predicted from singular values and tested with a few lines of code.

    Open editable notebook · Download .ipynb · Chapter 20

  • Which sampling times reveal the velocity of an oscillator?

    A sensor measures displacement while a controller needs velocity as well. Use the exact free vibration between two readings to recover the missing state, then quantify how a poorly chosen sample interval amplifies measurement noise.
