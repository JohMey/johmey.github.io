Control engineering · Notation and assumptions

Read each defining equation with its assumptions and units, then follow the link to the argument that gives the equation its meaning.

Complementary sensitivity

\[T(s)=L(s)/[1+L(s)]\]

For the same feedback configuration S plus T is one. Measurement noise and plant-input disturbances reach the output on different paths.

Derivation · Separating reference tracking from disturbance rejection

Discrete pole

\[z=e^{sT_s}\]

This maps a continuous modal exponent into a sampled multiplier over interval Ts. Different continuous frequencies can give the same sampled phase.

Derivation · Sampling, saturation and commissioning

Loop delay

\[L_{\rm delayed}(i\omega)=L(i\omega)e^{-i\omega\tau}\]

A pure delay leaves the magnitude unchanged and adds frequency-dependent phase. Use angular frequency when converting a margin to seconds.

Derivation · How much transport delay a feedback loop can tolerate

Observability

\[\mathcal O=[C^\mathsf T,(CA)^\mathsf T,\ldots]^\mathsf T\]

Full column rank in the standard finite-dimensional linear model allows the initial state to be inferred from ideal output history. Noise still controls achievable precision.

Derivation · States, reachability and estimation

Sensitivity

\[S(s)=1/[1+L(s)]\]

For a scalar unity negative-feedback loop this gives one closed-loop transfer. The point where a disturbance enters determines which transfer the observer measures.

Derivation · Uncertainty envelopes and robust stability

Transfer function

\[G(s)=Y(s)/U(s)\]

State the input, output and zero initial condition. Interconnection signs and unmodelled dynamics affect what a measured closed-loop response represents.
