Condition number

\[\kappa(A)=\|A\|\|A^{-1}\|\]

For an invertible square matrix choose a compatible norm. Conditioning describes data sensitivity, while stability refers to the algorithm processing the data.

Derivation · Conditioning and backward error

Krylov subspace

\[\mathcal K_k(A,b)=\operatorname{span}(b,Ab,\ldots,A^{k-1}b)\]

The starting vector determines which parts of the spectrum are visible. Orthogonalisation avoids storing nearly dependent raw powers.

Derivation · Arnoldi iteration and GMRES

Orthogonal projector

\[P=QQ^\mathsf T\]

Columns of Q must be orthonormal in the stated real inner product. Least squares removes the component of the data orthogonal to the fitted range.

Derivation · Least squares and orthogonal factorisation

Residual

\[r=b-A\hat x\]

A small residual tests the computed equation. Converting it into an error estimate needs information on the inverse or the troublesome singular directions.

Derivation · Iterative refinement and backward error

Schur complement

\[S=D-CA^{-1}B\]

Eliminate the first block of a partitioned system by solving with A. Forming an explicit inverse is unnecessary and may discard useful structure.

Derivation · Eliminating constraints with Schur complements

Singular value

\[Av_i=\sigma_i u_i\]

Input and output directions can live in different spaces. A small positive singular value can cause large inverse amplification.

Derivation · Singular values and minimum-norm solutions
