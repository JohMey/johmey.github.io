From first principles

Extract a root enclosure from the mean value theorem

Suppose a differentiable scalar \(f\) has a root \(r\) in a current interval \(X\), and choose a midpoint or other point \(m\in X\). The mean value theorem relates \(f(m)\) to the derivative at an unknown intermediate point. If an interval \(D\) contains every derivative on \(X\) and excludes zero, then

\[0=f(m)+f'(\xi)(r-m),\qquad r\in m-\frac{f(m)}{D}.\]

Dividing by the entire derivative interval accounts for all possible intermediate slopes. Intersect with the original interval to retain both facts about the root,

\[X_{\rm new}=X\cap\left(m-\frac{f(m)}{D}\right).\]

An empty intersection proves there was no root in \(X\). A nonempty intersection alone does not establish existence; a verified sign bracket supplies a separate existence proof. Outward-rounded evaluations of the function and derivative bounds are necessary for a numerical certificate. If \(D\) contains zero, ordinary interval division cannot justify this simple enclosure.

Derivation and applications

Include function-evaluation uncertainty in an interval Newton step

A derivative enclosure is insufficient for a reliable root bound when the value at the midpoint is itself uncertain. Suppose every root under consideration lies in a real interval \(X\), and \(f'\) stays between two verified positive bounds \(0<d_-\le d_+\) throughout \(X\). At \(m\in X\) the numerical or measured value supplies only \(f(m)\in[u,v]\). For any root \(r\) in the interval the mean value theorem now gives

\[r=m-\frac{f(m)}{f'(\xi)}\in m-\frac{[u,v]}{[d_-,d_+]} .\]

If \(0\le u\le v\), all ratios are nonnegative. The smallest ratio uses the smallest numerator and largest denominator; the largest uses the largest numerator and smallest denominator. Consequently

\[X_{\rm new}=X\cap[m-v/d_-,\,m-u/d_+] .\]

If \(u<0<v\), both extremes instead use the smallest denominator. The new candidate interval becomes

\[X_{\rm new}=X\cap[m-v/d_-,\,m-u/d_-] .\]

These enclosures retain any root in \(X\); existence still needs independent evidence such as verified opposite signs at the ends. A sign-uncertain midpoint can prevent further narrowing once evaluation error dominates. Tightening only the derivative interval need not improve the result materially in that regime. For machine-certified endpoints, rounded arithmetic must widen each interval as needed.

Worked example

Enclose a square root with a rounded residual

For \(f(x)=x^2-2\) on \([1.4,1.5]\), use \(m=1.45\), verified derivative interval \([2.8,3.0]\), and a coarse residual enclosure \([0.102,0.103]\). Then \(X_{\rm new}=[1.45-0.103/2.8,\,1.45-0.102/3.0]\), which is contained in the outward-rounded interval \([1.41321,1.41600]\). The endpoint signs of the original interval establish existence, and the positive derivative makes the root unique.

Second application

Recognize the resolution floor of a sensor

A separate monotone balance has derivative in \([4,5]\). At \(m=3\), its instrument reads zero within \(\pm0.020\). The sign-uncertain formula gives \(r\in[2.995,3.005]\) for any root in the working bracket. To certify a half-width \(0.001\) using the same lower derivative bound, the residual measurement must be resolved to \(\pm0.004\) or better unless additional location information is available.

From a point step to an enclosure

Let \(f\) have a continuous derivative throughout a closed interval \(I\). Choose \(m\in I\) and compute an interval \(D\) containing every derivative value on \(I\). If \(0\notin D\), any root \(r\in I\) satisfies \(0=f(m)+f'(\xi)(r-m)\) by the mean value theorem. Therefore \(r\in N=m-f(m)/D\). Intersecting \(N\) with \(I\) retains every possible root. An empty intersection certifies that the original interval contained none. Since the derivative has a fixed sign, there can be at most one.

Existence needs an additional argument. Opposite endpoint signs suffice by continuity. Alternatively if \(N\) lies strictly inside \(I\), its extremal corrections force a sign change or a zero at \(m\): for an increasing function and \(f(m)>0\), moving left by \(f(m)/\min D\) decreases the function by at least \(f(m)\). That point lies in \(I\). The other signs follow by reversing the interval or taking \(-f\). This argument explains why proper containment has stronger meaning than partial overlap.

Enclose a square root

For \(f=x^2-2\) on \([1,2]\), derivatives lie in \([2,4]\). The midpoint gives \(f(1.5)=0.25\), so \(N=[1.5-0.25/2,1.5-0.25/4]=[1.375,1.4375]\). Its width is one sixteenth of the starting width. Ordinary Newton at 1.5 would give \(1.416\overline6\); an accurate single estimate carries a different type of evidence from an enclosure with guaranteed endpoints.

Choose \(m=1.40625\) in the new interval. Now \(f(m)=-0.0224609375\) and \(D=[2.75,2.875]\). The next interval lies between \(1.40625+0.0224609375/2.875\) and \(1.40625+0.0224609375/2.75\), approximately \([1.414062,1.414418]\) with endpoints rounded outward. For narrower intervals the variation in \(1/f'\) shrinks proportionally to width when \(f'\) is Lipschitz and bounded away from zero. Because \(f(m)\) is itself proportional to width near the root, the new width often decreases quadratically.

Keep the certificate valid

Each arithmetic operation needs outward rounding when performed in floating point. Rounding inward can exclude a root even when the algebra is exact. If a derivative interval crosses zero, ordinary interval division cannot give a single bounded correction. Subdivide and test again, or use an independent enclosure argument. For \(x^2\) on \([-1,1]\), repeated subdivision approaching zero encounters a true double root where the derivative vanishes. The usual simple-root contraction argument does not apply there. A sign-change test also misses this root because the function just touches the axis.

Use a stronger derivative enclosure when possible

For \(f(x)=x+x^3\) on \([-1,1]\), the derivative is \(1+3x^2\). Multiplying two independent copies of the interval \([-1,1]\) gives the loose product \([-1,1]\), leading to the derivative enclosure \([-2,4]\). Treating the expression as an actual square instead gives \([1,4]\), excluding zero. The latter bound allows the interval Newton step at the midpoint to collapse directly onto the root zero. Both interval results enclose every derivative, but keeping algebraic dependence between two identical factors greatly improves the certificate.

Extend enclosure to a system using a preconditioned map

For a differentiable vector function \(F\), choose an approximate inverse Jacobian \(C\), a box \(X\) and a centre \(m\) inside it. Roots of \(F\) are fixed points of \(G(x)=x-CF(x)\), and the converse holds when \(C\) is nonsingular. The integral mean-value identity expresses \(G(x)\) as \(m-CF(m)\) plus an averaged derivative \([I-CJ]\) acting on \(x-m\). If every true Jacobian on the box is enclosed in an interval matrix, interval arithmetic produces an outer enclosure for the complete image \(G(X)\). This is the basis of a Krawczyk-type inclusion test.

A simple sufficient certificate is to bound the induced infinity norm of \(I-CJ(x)\) by \(q<1\) throughout the box and show that \(G(X)\subseteq X\). The closed box is complete, so the contraction theorem then gives a unique root in it. In a cube of radius \(\rho\) around \(m\), it suffices that \(\|CF(m)\|_\infty+q\rho\le\rho\). If this test fails, no conclusion follows: the box may be too large, \(C\) may be a poor inverse, or the interval enclosures may have lost correlation between entries.

Certify a coupled nonlinear equilibrium with one matrix bound

Let \(F_1=x+0.1y^2-1,\ F_2=y+0.1x^2-1\). Use centre \(m=(0.90,0.90)^T\), cube radius 0.05 and \(C=I\). Each central residual is

\[0.90+0.081-1=-0.019.\]

The derivative of \(G(x,y)=(1-0.1y^2,1-0.1x^2)\) has zero diagonal and off-diagonal entries \(-0.2y,-0.2x\). On the cube both coordinate magnitudes are at most 0.95, so every absolute row sum is at most 0.19. The total displacement bound is

\[0.019+0.19(0.05)=0.0285<0.05.\]

This verifies existence and uniqueness within the box without assuming that the answer has equal coordinates.

The first map evaluation gives \((0.919,0.919)\). A tighter direct image uses the monotonic decrease of \(1-0.1s^2\) for positive \(s\): both coordinates land in \([1-0.1(0.95)^2,1-0.1(0.85)^2]=[0.90975,0.92775]\). Uniqueness together with symmetry under swapping coordinates forces the root in this box to satisfy \(x=y=s\). The scalar equation \(s+0.1s^2=1\) then gives

\[s=-5+\sqrt{35}\approx0.91608,\]

which lies within the certified interval.

The other scalar root \(-5-\sqrt{35}\) lies far outside the box. The local certificate excludes no roots elsewhere and must not be reported as global uniqueness. In floating-point certification, round every bound outward, particularly evaluations that nearly touch a face. A convenient approximate Newton iterate can suggest the centre, while the independent box computation supplies the actual existence claim.

Consider expanding the initial certificate all the way to the cube \([-6,6]^2\). The corresponding row-sum bound would be 1.2, violating the simple contraction criterion, and the scalar symmetry reduction exhibits two roots in that cube. Thus in this enlarged domain failure of the uniqueness test correctly reflects an actual multiplicity problem. On a moderately larger domain the very same bound might merely be too conservative. Either situation calls for subdivision or sharper derivative information, rather than interpreting a failed sufficient test as evidence of nonexistence.

Subdividing preserves the distinction because the certificate can be applied independently on each smaller closed box.

Enclose a root using a derivative interval

Start with \(I=[1.5-h,1.5+h]\) containing the positive root of \(x^2-2\). By the mean value theorem the root lies in \(1.5-0.25/[3-2h,3+2h]\). Take care when dividing by a positive interval and subtracting it.
