Choosing a step from a local model

For a scalar residual \(f\), finding a zero also minimises \(\phi=f^2/2\) if a zero is attainable. Near \(x\), approximate \(f(x+s)\) by \(f(x)+f'(x)s\), yielding a quadratic model \(m(s)=(f+f's)^2/2\). Minimise this model subject to \(|s|\le\Delta\). In one dimension this clips the ordinary Newton step to the interval; when \(f'=0\), the model contains no preferred direction.

Measure both predicted and actual decrease. Provided the predicted decrease is positive, define

\[\rho=\frac{\phi(x)-\phi(x+s)}{m(0)-m(s)}.\]

A ratio near one supports the local model. A negative ratio means that a predicted gain produced an actual loss. Shrink the radius and repeat from the same point. A successful boundary step can justify enlarging the next radius. These decisions require an extra residual evaluation and do not require a globally accurate Taylor approximation.

Two proposals for the same equation

For \(f(x)=x^2-2\) at \(x=0.2\), \(f=-1.96\), \(f'=0.4\). The full Newton proposal \(s=4.9\) lands at \(5.1\), where the residual is 24.01. The linear model predicted zero. The merit function rises catastrophically.

With radius one, \(s=1\) gives \(x=1.2\) and \(f=-0.56\). Predicted merit decrease is

\[(1.96^2-1.56^2)/2=0.704.\]

Actual decrease is

\[(1.96^2-0.56^2)/2=1.764.\]

The ratio exceeds one because the curvature accelerated the improvement. A large ratio is possible and has a direct interpretation.

Look along the step before accepting it

Compare the true merit function and the local model along positive steps from a starting value below the root. Move the trust radius and read the ratio for the constrained minimiser. Locate a region in which predicted and observed changes have opposite signs.

Is a small gradient of \(f^2/2\) sufficient to certify a root?

Worked solution

Its gradient is \(ff'\). It can vanish either at a root or at a stationary residual. Report the original residual and test feasibility to distinguish these outcomes.
