Embedded error estimate

\[e=y_{n+1}^{[p]}-y_{n+1}^{[p-1]}\]

Two formulas share stages and estimate a local error. The controller also needs absolute and relative scales for each component.

Derivation · Adaptive steps and event locations

Event transversality

\[\dot g=\partial_tg+\nabla g\cdot f\]

For a simple event this directional derivative is nonzero. Near grazing, a small state error can create a much larger error in the event time.

Derivation · Locating a grazing event between time steps

Local truncation error

\[d_{n+1}=y(t_{n+1})-\Phi_h(y(t_n))\]

This is the one-step defect from exact starting data. Some conventions divide it by h. State the convention before comparing local and global orders.

Derivation · Initial values and propagated error

Shooting residual

\[F(s)=B(y(t_f;s))\]

Here s encodes missing initial data and B the final boundary condition. An unstable trajectory map can make the residual badly conditioned even with an accurate initial-value solver.

Derivation · Shooting for two-point boundary values

Stability function

\[y_{n+1}=R(h\lambda)y_n\]

On the scalar linear test equation, absolute stability depends on the point h times lambda. It gives only part of the story for a nonnormal matrix or nonlinear problem.

Derivation · Absolute stability and stiffness

Symplectic map

\[(D\Phi)^\mathsf T J(D\Phi)=J\]

This is preservation of the canonical symplectic form. It provides control of long-time structure without guaranteeing that every trajectory has the exact phase.
