Dynamics and numerical time integration · 1. Find a crossing between accepted time steps

An integrator can approximate a trajectory accurately yet report a poor switch time. Construct a continuous interpolant, relate a state error to an event-time error and inspect what happens when a trajectory merely touches a threshold.

An event is a root of a composite function

Let \(y'=f(t,y)\) and let a sensor or change of dynamics be described by \(g(t,y)=0\). Along an exact trajectory the scalar event function is \(h(t)=g(t,y(t))\). A simple event at \(t_*\) satisfies

\[\dot h_*=g_t+g_yf\ne0.\]

If approximate trajectory or sensor evaluation introduces error \(\delta h\), linearisation around the crossing gives

\[\delta t\simeq-\delta h/\dot h_*.\]

A small state error can therefore imply a much larger time error if the crossing is nearly tangential. Reporting an event timestamp to machine precision after bisecting a low-order interpolant is not equivalent to knowing the physical crossing time that accurately.

Consider a dimensionless unit-frequency oscillator with \(y=\cos t,\ y'=-\sin t\) during the first half cycle. Its first falling crossing of threshold \(a\in(0,1)\) occurs at \(t_*=\arccos a\), with slope \(-\sqrt{1-a^2}\). At \(a=0.5\), a positive vertical interpolation error \(10^{-3}\) can delay the crossing by about \(0.00115\) time units. At \(a=0.9999\) the same linear estimate is about 0.0707, comparable with or larger than the event time itself; the simple linear local approximation then also fails. At precisely \(a=1\) the surface is tangent at the maximum and sign-change tests can miss it altogether.

Construct a state and slope interpolant on one accepted interval

Suppose samples of state and derivative are available at \(t_n,t_{n+1}=t_n+h\). Write \(s=(t-t_n)/h\) and choose a cubic \(p(s)\) matching \(p(0)=y_n,p(1)=y_{n+1},p_s(0)=hf_n,p_s(1)=hf_{n+1}\). Solving these four linear conditions gives

\[p=(2s^3-3s^2+1)y_n+(s^3-2s^2+s)hf_n+(-2s^3+3s^2)y_{n+1}+(s^3-s^2)hf_{n+1}.\]

For an exact scalar trajectory sufficiently smooth in time, the Hermite error is \(y(t)-p(t)=y^{(4)}(\xi)(t-t_n)^2(t-t_{n+1})^2/4!\), bounded by \(h^4\max|y^{(4)}|/384\). Linear interpolation instead has error bounded by \(h^2\max|y''|/8\). Combine either bound with a known lower bound on \(|\dot h|\) in a bracket to bound event-time error. In an actual ODE solve, \(y_n,f_n\) are numerical, so interpolation and integrated state errors both contribute. A high-order interpolant cannot repair incorrect endpoint data or sample a discontinuity assumed smooth.

Bracket on the physical trajectory and restart after a transition

At each accepted interval compare event values at both ends. For a simple crossing of the requested direction, solve \(g(t,p(t))=0\) inside that interval using a bracketed root finder. The bracket controls the algebraic root-finding error; independent time-step refinement measures trajectory error. If the dynamics change at the event, truncate the old step there, apply any specified reset \(y^+=R(t_*,y^-)\) and restart the integrator under the new right side. Propagating the old smooth interpolant through a change of dynamics can corrupt both state and subsequent event ordering.

If a surface stays exactly active over a finite interval, repeated detection at the same time can stall the integration. A model of contact, hysteresis or directional rearming may be physically appropriate, depending on what the event means. Merely nudging the time forward by an arbitrary tolerance can skip a nearby second event. Similarly two opposite crossings within one large accepted interval may yield equal endpoint signs. A maximum step guided by known physical timescales, supplementary extrema detection or an analytically enclosed event function can be needed. Accuracy control on the smooth state alone does not guarantee detection of every specified surface crossing.

Compare interpolation errors independently of the propagation error

The calculator uses exact cosine endpoint samples and their derivatives, then locates the first falling crossing on a uniform time grid by linear or cubic Hermite interpolation. The curves show error against step spacing on a logarithmic vertical scale. Their irregular minima occur when a grid point happens to coincide with the event. Look for the error envelope over several spacings. At threshold 0.5 the exact result is 1.047198 s. Moving the threshold changes both the crossing slope and its position relative to the sampled grid.

Distinguish uncertainty in the threshold from time discretisation

Two clocks can agree on an event and still report a poorly determined arrival time if the physical threshold is uncertain. For a calibrated level \(a\) the falling crossing solves \(\cos t_*=a\), so implicit differentiation gives

\[dt_*/da=-1/\sqrt{1-a^2}.\]

A level error of \(0.002\) near \(a=0.5\) produces a timing uncertainty of about \(0.00231\) s for the unit-frequency benchmark. At \(a=0.9\) the same device gives \(0.00459\) s. Close to the turning point the trace is almost horizontal. Reducing the root finder's tolerance cannot remove that physical loss in sensitivity.

If the numerical trajectory also has a known absolute state error bound \(\eta\), divide that bound by a lower bound on the crossing speed in the bracket. The result is a deterministic timing allowance. An independent random threshold error has a standard deviation and calls for a statistical interpretation. Adding those numbers in quadrature would need a probability model for both. Reporting the two separately preserves what the measurement and the solver actually established.

Dynamics and numerical time integration · 2. A delayed feedback model needs a history, not one starting value

A controller responds to the measured displacement one time delay ago. Construct its solution in successive intervals, track propagated derivative discontinuities and derive the point at which increasing delay can destabilise negative feedback.

Specify the additional data an ordinary initial value omits

For \(t\ge0\) consider \(y'(t)=-a y(t-\tau)\) with positive constant gain \(a\) and delay \(\tau>0\). The derivative at the start depends on \(y(-\tau)\); an initial value \(y(0)\) alone is insufficient. Supply a history \(y(t)=\phi(t)\) on \([-\tau,0]\), continuous at zero for a continuous state. Two preparations sharing \(y(0)\) but different earlier values can immediately develop different slopes. This is why treating a delay as a new algebraic coefficient in an ODE solver without a history buffer changes the physical problem.

Take constant history \(\phi=1\). For \(0\le t\le\tau\), the delayed input is one and \(y=1-at\). For \(\tau\le t\le2\tau\), the derivative is \(-a[1-a(t-\tau)]\); integrate from \(t=\tau\) to get

\[y=1-at+a^2(t-\tau)^2/2.\]

On the next interval another integral gives

\[y=1-at+a^2(t-\tau)^2/2-a^3(t-2\tau)^3/6.\]

Each new interval solves an ordinary forced equation with known earlier right-side data. This is the method of steps. A smooth-looking initial history can nevertheless mismatch derivatives: here the left derivative at zero is zero while the equation supplies \(-a\) on the right.

Trace how a step mismatch propagates through the delay

At \(t=\tau\) continuity of \(y\) at zero makes \(y'\) continuous, but \(y''(t)=-a y'(t-\tau)\) inherits the earlier jump in \(y'\). At \(2\tau\) the discontinuity appears in the third derivative. High-order adaptive ODE error formulas assume smooth derivatives within an interval. Marking known breakpoints and integrating separately across the delay intervals avoids applying a high-degree interpolant through an unacknowledged loss of smoothness. With several delays, sums of delay lengths can generate additional event locations and their bookkeeping matters. A discontinuity in the physical forcing can also generate new fronts of reduced regularity.

Within a method-of-steps solver, values \(y(t-\tau)\) usually lie between stored previous mesh points. Dense output supplies their interpolation. Its error feeds directly into the next interval's right side and can limit global accuracy even when the ODE time-step rule has higher formal order. Maintain enough history to cover the largest delay and requested outputs, and preserve the known one-sided behaviour at breakpoints. If a trial step is longer than the delay its stages may refer to the current unknown interval; an algorithm must either constrain that step or solve the resulting within-step interpolation problem consistently. A generic lookup of the last stored value instead creates an unintended zero-order-held feedback law.

Background · Can smooth data prevent the first derivative jump?

A constant history \(\phi(t)=1\) has zero left derivative at the start. The equation \(y'=-a\,y(t-\tau)\) demands right derivative \(-a\), creating an immediate mismatch. A history with \(\phi(-\tau)=1\) and \(\phi'(0^-)=-a\) instead matches the first derivative. For example, choose \(\phi(t)=1-a(t+\tau)\) on the history interval.

Matching a first derivative does not guarantee a smooth second derivative. Differentiating the equation once shows that the next matching condition would be

\[\phi''(0^-)=-a\,\phi'(-\tau^+).\]

For the linear history, the two sides are zero and \(a^2\). The mismatch has moved up by one derivative. A high-order interpolant across the start may therefore still lose order even though the trajectory and its tangent look continuous.

Derive a delay-induced change of oscillatory stability

For a constant-coefficient retarded equation try \(y=e^{st}\). Substitution gives

\[s+a e^{-s\tau}=0.\]

Unlike a polynomial characteristic equation, this transcendental equation generally has infinitely many roots. A pair crosses the imaginary axis when \(s=i\omega\), giving \(a\cos(\omega\tau)=0,\ \omega-a\sin(\omega\tau)=0\). For positive \(\omega\), the first crossing is at \(\omega=a,\ a\tau=\pi/2\). With negligible delay the model behaves like the stable ODE \(y'=-ay\). The crossing indicates that negative feedback acting on old information can become destabilising; stability of the zero-delay ODE is no guarantee for arbitrary delay.

To check crossing direction, differentiate \(s+a e^{-s\tau}=0\) at constant \(a\), obtaining \(ds/d\tau=-s^2/(1+\tau s)\) after using the characteristic equation. At \(s=ia\) its real part is \(a^2/[1+(a\tau)^2]>0\). Increasing delay moves this pair into the unstable half-plane. A numerically observed sign-changing transient alone does not prove instability, as stable delay systems can oscillate while decaying. Compare an envelope over successive periods with the characteristic roots and refine both time discretisation and history interpolation. An unstable numerical discretisation can otherwise imitate a feedback-induced growth.

Compare a stored history with the method-of-steps solution

The delay is the time unit and the history on the preceding interval is one. The calculator integrates an explicit Euler update with an integer number of steps per delay so it can read the delayed state exactly at a stored grid index. The comparison curve evaluates the exact piecewise polynomial. Its kth contribution starts after k minus one delay intervals and has coefficient given by the kth power of minus the dimensionless feedback divided by k factorial. This follows by repeatedly integrating the previous interval’s polynomial, so it is independent of the Euler recurrence.

At feedback one, inspect the exact values after one, two and three delays before refining the grid. Euler already integrates the constant derivative on the first interval exactly, while errors enter on later intervals. Change the feedback across π/2 and compare the oscillation envelope. Six displayed delays are useful for checking the calculation but can be too short to measure slow growth close to threshold. A stable-looking short record does not replace the characteristic-root analysis. Because the grids here align with the delay, this experiment isolates stepping error and does not test a general off-grid history interpolator.

Dynamics and numerical time integration · 3. Solving a two-point boundary problem without guessing the start slope

When endpoint conditions act on different sides of an interval, shooting can amplify a tiny initial error. Construct a cubic collocation system, test its continuous differential residual and quantify which boundary-value solution the residual actually certifies.

Sensitivity of shooting need not be sensitivity of the physical solution

Take \(y''=\kappa^2y\) on \(0\le x\le1\), with \(y(0)=1,\ y(1)=0\). The solution \(y=\sinh[\kappa(1-x)]/\sinh\kappa\) decays from the left. To shoot from the left, introduce unknown slope \(s\), yielding endpoint \(y(1)=\cosh\kappa+(s/\kappa)\sinh\kappa\). The correct slope is \(-\kappa\coth\kappa\) and its error is magnified by \(\sinh\kappa/\kappa\) at the far end. For \(\kappa=20\) this factor is about \(1.21\times10^7\). Even an initial slope accurate to \(10^{-10}\) can cause a far-end mismatch of order \(10^{-3}\). The mathematical boundary solution can remain well behaved while this particular representation suffers cancellation of large growing and decaying components.

A collocation boundary solver instead treats approximate states at many locations as simultaneous unknowns and enforces both boundary conditions directly. Write the equation as first-order system \(Y'=(v,\kappa^2 y)^T=F(x,Y)\), \(Y=(y,v)\). On each panel \([x_i,x_{i+1}]\) choose a cubic Hermite polynomial using unknown endpoint states and endpoint slopes fixed by \(F_i,F_{i+1}\). This already imposes the differential equation at both endpoints. Require the polynomial derivative to satisfy the ODE also at the midpoint. Matching yields two equations for each panel, with the boundary equations closing the overall algebraic system.

Derive a residual with only three right-side evaluations per panel

For panel width \(h\), Hermite interpolation at the midpoint gives

\[Y_m=(Y_i+Y_{i+1})/2+h(F_i-F_{i+1})/8.\]

Its derivative there is \(p'_m=3(Y_{i+1}-Y_i)/(2h)-(F_i+F_{i+1})/4\). Equating this with \(F_m=F(x_i+h/2,Y_m)\) yields

\[Y_{i+1}-Y_i-\frac h6(F_i+4F_m+F_{i+1})=0 .\]

This is a three-point Lobatto collocation relation, resembling Simpson quadrature with a midpoint state determined by the same cubic. Neighbouring panels share endpoint states and slopes, constructing a continuously differentiable piecewise approximation for a smooth right side. The nonlinear algebraic Jacobian has local block structure apart from boundary conditions and a few global unknowns. Dense finite differencing of the entire state would discard that structure and can dominate a large adaptive solve.

As a simple independent test take the scalar ODE \(y'=\lambda y\). With \(z=h\lambda\), substitution of \(Y_m\) yields a one-panel transfer \(R(z)=(1+z/2+z^2/12)/(1-z/2+z^2/12)\), agreeing with \(e^z\) through \(z^4\). The symmetry \(R(-z)=1/R(z)\) checks the derivation. At large negative \(z\), \(R(z)\to1\), so the local solution formula is not strongly damping for unresolved stiff modes. Global enforcement of boundary conditions and adaptive spatial resolution remain important: a stable algebraic solve need not resolve a very thin physical layer.

Interpret a continuous residual through a stability estimate

A collocation residual vanishes at the points where it was imposed, so checking only those values tests the nonlinear algebraic solve, not the differential approximation between points. Evaluate the continuous defect \(d(x)=p'(x)-F(x,p(x))\) at independent points or use its suitably weighted panel norm. Refine where the residual is large, especially where the solution changes rapidly, and enforce the boundary conditions independently. A mesh with many uniform far-interior points can inefficiently resolve a solution having a layer of thickness \(1/\kappa\) near a single wall.

For a scalar linear elliptic boundary problem \(-y''+\kappa^2 y=f\) with zero endpoint error, an approximation with smooth enough derivatives has error governed by \(-e''+\kappa^2e=r\). If \(\|r\|_\infty\le\epsilon\), a maximum-principle argument gives \(\|e\|_\infty\le\epsilon/\kappa^2\) for \(\kappa>0\): at an interior positive error maximum, \(-e''\ge0\), and similarly for the negative minimum. This bound links a differential residual in the same formulation to solution error under the stated boundary conditions. A residual in a differently scaled first-order system requires its own inverse stability estimate. Near a nonunique boundary solution an apparently tiny defect can correspond to a much larger state error.

A solution satisfying the nonlinear algebraic conditions of the chosen discretisation need not preserve positivity of the continuum field at every point.

Dynamics and numerical time integration · 4. Why stiff stability does not guarantee the expected order

A differential equation is constructed to have a smooth, known solution and a rapidly damped error mode. Use it to distinguish stability of the homogeneous equation, tracking of a moving target and the effect of off-grid stage forcing.

Choose an exact solution before increasing stiffness

Let \(\lambda<0\), let \(\phi(t)\) be a smooth specified function, and solve the Prothero–Robinson model \(y'=\lambda[y-\phi(t)]+\phi'(t)\), \(y(0)=\phi(0)\). The exact solution is \(y(t)=\phi(t)\) for every \(\lambda\). For an initial mismatch \(e_0\), the error evolves \(e(t)=e_0e^{\lambda t}\). Thus the observed slow solution and fast relaxation timescale can be varied independently. This makes the model an incisive verification case for a stiff integrator: changing \(\lambda\) leaves the exact waveform fixed while altering how errors created by discrete stages are damped.

A stability function \(R(h\lambda)\) describes propagation of errors for the homogeneous test \(y'=\lambda y\). A-stability constrains \(|R(z)|\le1\) over the left half-plane. L-stability additionally requires \(R(z)\to0\) as \(|z|\to\infty\) in the stable stiff limit. Neither definition alone describes how a method evaluates a time-dependent forcing at its internal stages. Stage order and stiff accuracy can matter when those stage errors are multiplied by large \(|\lambda|\). Observing bounded output on a homogeneous damping test does not establish a method's full formal order on a forced stiff problem.

Calculate the error recurrence of backward Euler and the trapezoidal rule

Write \(e_n=y_n-\phi_n,\ z=h\lambda\). Backward Euler evaluates the whole right side at \(t_{n+1}\). Collect terms after subtracting the exact target:

\[(1-z)e_{n+1}=e_n+\phi_n-\phi_{n+1}+h\phi'_{n+1}.\]

The forcing defect begins at \(h^2\phi''_{n+1}/2\). Its effect on the next error is divided by \(1-z\). The rapidly decaying homogeneous mode is also divided by that factor. This can make backward Euler track a particular smooth imposed target surprisingly well in the very stiff regime even though its classical nonstiff order is one. Its behaviour should be assessed in the desired observables and step–stiffness range, rather than ranked solely by the formal method label.

For the trapezoidal rule the corresponding equation is

\[(1-z/2)e_{n+1}=(1+z/2)e_n+\phi_n-\phi_{n+1}+\tfrac h2(\phi_n'+\phi_{n+1}').\]

The defect is the trapezoidal quadrature error in the derivative and begins at order \(h^3\). However, its homogeneous factor tends to \(-1\) when \(z\to-\infty\), so a pre-existing fast error can survive as a sign-alternating numerical component for many steps. With \(z=-100\) the factors are \(1/101=0.00990\) for backward Euler and \(-49/51=-0.96078\) for trapezoid. Both schemes are A-stable. Only the first immediately damps this unresolved mode. Event resets, inconsistent initial preparation or changing external loads can seed it.

A midpoint constraint can force endpoint drift

Implicit midpoint uses \(y_{n+1}-y_n=h[\lambda((y_n+y_{n+1})/2-\phi_m)+\phi'_m]\). For fixed \(h\) and large negative \(\lambda\), finite numerical states require the stage average to approach \(\phi_m\). Thus \(y_{n+1}\simeq2\phi_m-y_n\). The endpoints inferred from this interior constraint need not land on \(\phi_{n+1}\). Compare with trapezoid, which shares exactly the same scalar homogeneous stability function but evaluates two different times and states for nonlinear or time-dependent forcing.

With \(y_n=\phi_n\) and \(\phi(t)=t^2\), the limiting endpoint error is

\[2\phi(t_n+h/2)-\phi_n-\phi_{n+1}=-h^2/2.\]

The exact finite-\(z\) midpoint error starting from the target is \(zh^2/[4(1-z/2)]\). The trapezoidal derivative quadrature, in contrast, is exact for this quadratic target and keeps \(e_n=0\) at every step started exactly on it. Their common stability function did not predict their different forced response. In the midpoint example an alternating error can cancel at some output times, so inspecting only the final point at an even number of steps may obscure the largest per-step error. Compare all sampled times and separate propagated from newly injected defects.

Separate injected forcing error from a starting mismatch

This experiment uses the target t squared with step 0.1 s. It propagates the exact error recurrences of backward Euler, trapezoid and midpoint rather than estimating the difference by subtracting two large trajectories. The reference also includes the exponentially decaying initial mismatch. Move the stiffness control until a time step contains a hundred fast relaxation times. Dynamics and numerical time integration · 5. How far does an energy-preserving rotation lag behind?

Integrate uniform circular motion by the implicit midpoint rule. The points stay exactly on the energy circle in exact arithmetic. Derive the angle advanced at each step and measure the accumulated timing error.

From a midpoint balance to a rotation matrix

Write a two-component oscillator as \(v'=\omega Jv\), where \(J\) sends \((x,y)\) to \((-y,x)\). Choosing scaled coordinates makes both components comparable; for a mechanical oscillator one may take displacement and a suitably scaled speed. The generator is skew-symmetric, so \(d(v^Tv)/dt=\omega v^T(J^T+J)v=0\). The exact motion has angular advance \(h\omega\) over an interval \(h\).

Midpoint approximates the velocity at the midpoint of the segment joining the old and new states. This yields \((I-aJ)v_{n+1}=(I+aJ)v_n\) with \(a=h\omega/2\). Since \(J^2=-I\), multiplication by \(I+aJ\) eliminates the inverse and gives

\[R_h=(I-aJ)^{-1}(I+aJ)=\frac{(1-a^2)I+2aJ}{1+a^2}.\]

The coefficients of \(I\) and \(J\) have squares summing to one. They are the cosine and sine of the angle \(\theta_h=2\arctan a\). Thus every update preserves the squared radius. The angle differs from the exact \(h\omega\). Expanding the arctangent gives

\[\theta_h=h\omega-(h\omega)^3/12+O((h\omega)^5).\]

Over a fixed duration \(T=nh\), the leading accumulated angle error is \(-T\omega^3h^2/12\). This phase lag is especially visible after many periods even when a graph of energy looks perfect.

For comparison, explicit Euler takes the tangent line to its end point. Its amplification is \(\sqrt{1+(h\omega)^2}\). Studying both amplitude and timing identifies different defects of the two updates.

Put a clock on the unit circle

Let \(\omega=2\) rad/s, \(h=0.5\) s and \(v_0=(1,0)\). The half-step parameter is 0.5. The rotation sends the first point to \((0.6,0.8)\) instead of the exact \((\cos1,\sin1)\approx(0.5403,0.8415)\). Both radii are one. The angular deficit is \(1-2\arctan(0.5)\approx0.072705\) rad per update. After ten updates, the numerical clock is behind by 0.72705 rad or about 0.364 s of physical time.

With \(h=0.25\) s over the same five seconds the deficit is \(10-40\arctan(0.25)\approx0.20085\) rad. Its ratio to the coarse-step error is close to one quarter. In the notebook the rotation is built by a linear solve and its angle is measured from a dot product and an oriented area. These are independent ways to check the hand formula. Counting full turns requires retaining unwrapped increments; a final point alone cannot identify the number of completed turns.

Dynamics and numerical time integration · 6. From existence of a trajectory to the order of a time step

Establish what an initial-value solver approximates, derive Runge–Kutta order conditions for a general smooth vector field and construct an alternative high-order step by extrapolation.

Construct the trajectory on a short interval

Let \(f(t,y)\) be continuous on a time–state cylinder, bounded there by \(M\) and Lipschitz in \(y\) with constant \(L\). For initial value \(y_0\), seek a continuous curve in the closed sup-norm ball of radius \(R\) around \(y_0\). On an interval of length \(H\), apply

\[(Tz)(t)=y_0+\int_{t_0}^{t} f(s,z(s))\,ds.\]

If \(HM\le R\) and \(HL<1\), \(T\) maps the ball into itself and is a contraction. Iteration from the constant curve changes by at most \(HL\) times the preceding change. The geometric series of increments converges uniformly and the limit satisfies the integral equation. Differentiation gives the ODE. Two such limits have distance at most \(HL\) times their distance, hence coincide. Overlapping short cylinders extend the trajectory until continuation fails. For \(y'=y^2,\ y(0)=1\), the explicit \(1/(1-t)\) illustrates why local existence gives no promise at \(t=1\).

The perturbed integral inequality \(e(t)\le e_0+\int_0^t(Le(s)+d(s))ds\) leads, by an integrating factor for the right-hand side, to \(e(t)\le e^{Lt}e_0+\int_0^t e^{L(t-s)}d(s)ds\). It explains why a finite-time global error bound for a numerical solver needs an appropriate domain and a perturbation-growth estimate.

Collect elementary derivatives without losing branching terms

For an autonomous smooth \(f\), the first three elementary differentials are \(f,\ f'f,\ f''(f,f)\), together with the third-order chain \(f'(f'f)\). Represent a derivative acting on child differentials by a node with one branch per argument. A single node has order and density one. Recursively, a tree \(\tau=[\tau_1,\ldots,\tau_k]\) has \(|\tau|=1+\sum|\tau_j|\) and density \(\gamma(\tau)=|\tau|\prod\gamma(\tau_j)\). This factor follows by integrating the power of time once when a root is added. Multiplicities of identical branches give the same symmetry factor on the exact and numerical sides.

Define stage weights \(\Phi_i(\bullet)=1\). Taylor expanding each RK stage about the initial state replaces an integral for every child by a weighted stage sum. Consequently

\[\Phi_i([\tau_1,\ldots,\tau_k])=\prod_{\ell=1}^k\sum_j a_{ij}\Phi_j(\tau_\ell),\]
\[\sum_i b_i\Phi_i(\tau)=1/\gamma(\tau).\]

Matching every tree through order \(p\) gives classical order \(p\) for general sufficiently smooth vector fields. The local defect is order \(p+1\), yielding global order \(p\) under the perturbation bound above. For the fourth-order tree consisting of a root, a child, and two leaves on that child, the condition is \(b^TAc^2=1/12\), with \(c=A\mathbf1\) and the square componentwise. For a root with three leaves it is \(b^Tc^3=1/4\). A scalar linear test equation supplies only chains.

Select accuracy by spending more substeps

For a smooth problem over one macrostep \(H\), let \(T_{j,0}\) be its endpoint from \(N_j=2^j\) Euler substeps. At fixed \(H\), assume the endpoint error has an asymptotic expansion in powers of \(1/N_j\). This follows for smooth solutions by expanding the local error and propagating its coefficients. The leading term halves on doubling. Eliminate successive powers by

\[T_{j,k}=T_{j,k-1}+\frac{T_{j,k-1}-T_{j-1,k-1}}{2^k-1}.\]

For \(y'=y,\ y(0)=1,\ H=0.2\), the one- and two-substep estimates are \(1.2\) and \(1.21\), so the extrapolate is \(1.22\), close to \(e^{0.2}\). Four substeps give \(1.21550625\). Extrapolating once gives \(1.2210125\) and twice gives \(1.22135\). Use the separation between successive columns to estimate the lower-order local error. For a column of global order \(k+1\), a local tolerance suggests a trial next \(H\) proportional to the tolerance ratio raised to \(1/(k+2)\) if using that column's error estimate. Compare accepted advance per function evaluation at candidate orders. Restart the expansion after a discontinuity and impose the stability restriction of the underlying method.

When can a correct extrapolation tableau be misleading?

An unresolved event or a nonsmooth forcing invalidates the common power expansion across grids. Agreement among columns can then mean that every grid missed the same feature. Split at a known event and test the reconstruction against the defect in the integral equation.

Dynamics and numerical time integration · 7. Why consistent multistep formulas can fail under refinement

Derive the root condition for constant steps, propagate a local defect to a fixed end time and isolate a growing parasitic mode with a controlled starting error.

Turn the recurrence into a propagation matrix

Write a \(k\)-step scheme as \(\sum_{j=0}^k\alpha_j y_{n+j}=h\sum_{j=0}^k\beta_jf_{n+j}\) with \(\alpha_k=1\). Let \(\rho(z)=\sum\alpha_jz^j\) and \(\sigma(z)=\sum\beta_jz^j\). Substituting exact constant and linear solutions shows consistency requires \(\rho(1)=0,\ \rho'(1)=\sigma(1)\). For continuous differentiable exact solutions these conditions make the defect divided by \(h\) tend to zero. Higher derivatives determine the local order.

For \(f=0\) stack the latest \(k\) errors. Their propagation matrix is the companion matrix \(C\) of \(\rho\). A root \(r\) of multiplicity \(s\) contributes modes \(n^\ell r^n,\ 0\le\ell<s\) for nonzero roots. All powers of \(C\) stay bounded exactly when all characteristic roots lie in the closed unit disk and unit-modulus roots are simple. Interior repeated roots are harmless because exponential decay dominates their polynomial factors. This is null stability for constant step sequences.

Sum the defects over a fixed time

Let a convergent starter have maximum error \(E_0\), the local discrete defect be \(h\,\tau_n\), and \(f\) be Lipschitz with constant \(L\) on the solutions' domain. Repeated substitution using the bounded \(C^j\) first propagates the starter and each past perturbation. The Lipschitz terms contribute a sum of errors. For an implicit step take \(h\) sufficiently small to absorb its newest error term. With constants independent of \(h\),

\[E_n\le C_1(E_0+T\max|\tau_j|)+C_2h\sum_{i<n}E_i \le C_1(E_0+T\max|\tau_j|)\exp(C_2T).\]

Thus consistency and null stability imply convergence. Conversely, convergence for arbitrary convergent starting values on smooth problems forces bounded homogeneous propagation. If a root lies outside the disk, a vanishing initial perturbation can grow exponentially over \(T/h\) steps. For a repeated unit root choose an initial perturbation proportional to \(h^{s-1}\) in the generalised mode so that its final error stays finite and nonzero. Consistency is forced by testing constants and linear-in-time solutions under convergence for all equations, taking an irreducible multistep formula and the usual normalisation. This equivalence concerns fixed-order, constant-step schemes. Changing step ratios changes the propagation matrices.

Control the perturbation before changing the grid

For \(f=0\), take \(\rho=(z-1)(z-r)\), with \(r=-1\) or \(r=2\). Choose \(\sigma=1-r\) to make the associated formulas consistent. Initialise \(y_0=1,y_1=1+h^3\). The exact propagated endpoint error at \(N=1/h\) is

\[e_N=h^3(1-r^N)/(1-r).\]

For \(r=-1\) every error stays \(O(h^3)\). For \(r=2\) the growing factor eventually defeats every algebraic power. Exact starting data with no perturbations would hide this instability in the constant solution.

Transfer the experiment to the decaying state \(y'=-y\) by choosing \(\sigma(z)=(1-r)z\). Now the middle coefficient in the recurrence is \(1+r-h(1-r)\). A OneSimulation RK4 trajectory supplies a common starter and a separate full-step trajectory checked against \(e^{-1}\). Inject \(h^3\) into the starter and compare with the identical multistep solve without that injection. The difference isolates amplification along the recurrence.

"""Resolve a decaying signal with two consistent families of two-step methods."""
import matplotlib.pyplot as plt
import numpy as np
from onesim.numerics.time import ClassicalRungeKutta4TimeIntegrator

def decay(state, time):
    return (-state[0],)

def endpoint(parasitic, starter, h, n):
    previous, current = 1.0, starter
    for _ in range(1, n):
        previous, current = current, (1+parasitic-h*(1-parasitic))*current-parasitic*previous
    return current

method = ClassicalRungeKutta4TimeIntegrator()
counts = [6, 10, 14, 18, 22, 26]
fig, ax = plt.subplots(figsize=(7, 4), layout="constrained")
for parasitic in [-1, 2]:
    errors = []
    for n in counts:
        h = 1/n
        reference = (1.0,)
        starter = method.advance(reference, decay, h, time=0.)[0]
        for j in range(n):
            reference = method.advance(reference, decay, h, time=j*h)
        unperturbed = endpoint(parasitic, starter, h, n)
        perturbed = endpoint(parasitic, starter+h**3, h, n)
        errors.append(abs(perturbed-unperturbed))
        assert abs(reference[0] - np.exp(-1)) < 1e-5
    ax.semilogy(counts, errors, "o-", label=f"Parasitic root {parasitic:+d}")
    print(f"Root {parasitic:+d}: change at T=1 with 26 steps: {errors[-1]:.6g}")
print(f"Reference RK4 error with 26 steps: {abs(reference[0]-np.exp(-1)):.3g}")
ax.set(xlabel="Steps to time 1", ylabel="Final change caused by starting perturbation")
ax.legend()
fig.savefig("numerics-parasitic-root.png", dpi=170)

Dynamics and numerical time integration · 8. Why an accurate position can hide an inaccurate constraint force

Derive an energy test for implicit Runge–Kutta stages, then recover missing derivatives in a constrained model and calculate the accuracy lost by a multiplier.

Derive a nonlinear contractivity test

Suppose \(\langle u-v,f(u)-f(v)\rangle\le0\) for all relevant states. For two trajectories advanced by the same RK step, use \(D_i\) for each stage-state difference and \(g_i\) for the stage-slope differences. Substitute the stage identity \(D_i=d_0+h\sum_j a_{ij}g_j\) into the square of \(d_1=d_0+h\sum_i b_i g_i\). Collecting symmetric products gives

\[\|d_1\|^2-\|d_0\|^2=2h\sum_i b_i\langle D_i,g_i\rangle-h^2\sum_{ij}(b_i a_{ij}+b_j a_{ji}-b_i b_j)\langle g_i,g_j\rangle .\]

If \(b_i\ge0\) and the displayed symmetric coefficient matrix is positive semidefinite, the step cannot increase distances, assuming its nonlinear stage equations have a solution. This sufficient algebraic stability condition applies to nonlinear dissipative fields. For one-stage midpoint \(a=1/2,b=1\) the matrix is zero. Backward Euler \(a=b=1\) gives one. Both are contractive, but their scalar amplification limits as \(h\lambda\to-\infty\) are \(-1\) and 0 respectively. Only the latter damps an unresolved fast mode completely.

Recover the derivatives needed to see the multiplier

For index one, \(y'=f(y,z),\ 0=g(y,z)\) with \(g_z\) invertible, the implicit function theorem eliminates \(z\). Perturbing the algebraic constraint at fixed \(y\) by \(\epsilon\) gives \(\delta z=O(\epsilon/\sigma_{\min}(g_z))\). A mechanical position constraint has a different structure:

\[q'=v,\]
\[Mv'=F(q,v)-G(q)^T\lambda,\]
\[g(q)=0,\]
\[G=g_q .\]

Differentiating once gives \(Gv=0\). Differentiating again gives \(Gv'+g_{qq}[v,v]=0\). For positive definite mass and independent constraints the multiplier matrix \(GM^{-1}G^T\) is invertible and

\[(GM^{-1}G^T)\lambda=GM^{-1}F+g_{qq}[v,v].\]

The position formulation is a differentiation-index-three system in first-order form. Consistent initial data require both position and velocity constraints. A small position residual alone places no bound on multiplier error without regularity of its time dependence.

Derive a concrete order loss before interpreting an index

A manufactured constraint \(q=\sin t\) with \(q'=v,\ v'=\lambda\) has \(v=\cos t,\lambda=-\sin t\). Suppose a position solver introduces an alternating error \(e_n=(-1)^nh^p\). A backward difference for velocity amplifies it to \(2(-1)^n h^{p-1}\), and a second difference for the multiplier amplifies it to \(4(-1)^n h^{p-2}\). A smooth error series instead can gain cancellations. This distinction prevents assigning every index-three method a universal loss of two orders. Consistent stage order, constraint enforcement, regularity, initial conditions and the reconstruction used for the multiplier all affect the theorem.

Consider a converged Radau collocation step for the simpler index-two constraint \(q' =z,\ q=g(t)\). Its stages enforce the exact sampled \(g(t_n+c_i h)\). Starting from exact \(q_n\), the derivative stages equal those of the degree-\(s\) interpolant through the start and the \(s\) stage nodes. Stiff accuracy identifies the final stage as the output. Interpolant differentiation gives endpoint derivative error \(O(h^s)\) for smooth \(g\). The constrained position is exact here, illustrating precisely how classical differential-variable order fails to predict a multiplier measurement.

Derive an index-dependent rate in the constant-coefficient case

For a regular linear differential-algebraic pencil with constant coefficients, the algebraic part can be written as \(Nz'=z-g(t)\), where \(N^\nu=0\) and \(N^{\nu-1}\ne0\). Repeated substitution gives \(z=g+Ng'+\cdots+N^{\nu-1}g^{(\nu-1)}\). For a single Jordan chain, its last component specifies the input directly while the first can depend on its derivative of order \(\nu-1\). The highest derivative actually seen depends on the input direction and the reported component.

Interpolate \(g\) through \(s+1\) distinct nodes at fixed relative positions on an interval of length \(h\). Taylor expansion at the endpoint through degree \(s\) is exact for the interpolant. The residual nodal values are \(O(h^{s+1})\). Differentiating the fixed reference cardinal polynomials \(\ell\) times introduces \(h^{-\ell}\), giving \(O(h^{s+1-\ell})\) for derivative order \(\ell\le s\). Smoothness through degree \(s+1\) is required. If nodal observations themselves carry \(O(h^p)\) disturbances, their differentiated contribution is \(O(h^{p-\ell})\). The worst reconstructed component on an index-\(\nu\) chain therefore has order \(\min(s+1,p)-(\nu-1)\), when \(\nu-1\le s\) and the forcing couples to that last derivative. This is an error bound for this specified reconstruction. A different integrator's stage order and enforcement of the constraints need a separate analysis.

When converting residuals to a velocity or acceleration tolerance, budget the factors \(1/h\) and \(1/h^2\) and the conditioning of the constraint matrix.
