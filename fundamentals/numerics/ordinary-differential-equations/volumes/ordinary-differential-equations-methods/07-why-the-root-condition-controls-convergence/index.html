Why consistent multistep formulas can fail under refinement

Turn the recurrence into a propagation matrix

Write a \(k\)-step scheme as \(\sum_{j=0}^k\alpha_j y_{n+j}=h\sum_{j=0}^k\beta_jf_{n+j}\) with \(\alpha_k=1\). Let \(\rho(z)=\sum\alpha_jz^j\) and \(\sigma(z)=\sum\beta_jz^j\). Substituting exact constant and linear solutions shows consistency requires \(\rho(1)=0,\ \rho'(1)=\sigma(1)\). For continuous differentiable exact solutions these conditions make the defect divided by \(h\) tend to zero. Higher derivatives determine the local order.

For \(f=0\) stack the latest \(k\) errors. Their propagation matrix is the companion matrix \(C\) of \(\rho\). A root \(r\) of multiplicity \(s\) contributes modes \(n^\ell r^n,\ 0\le\ell<s\) for nonzero roots. All powers of \(C\) stay bounded exactly when all characteristic roots lie in the closed unit disk and unit-modulus roots are simple. Interior repeated roots are harmless because exponential decay dominates their polynomial factors. This is null stability for constant step sequences.

Sum the defects over a fixed time

Let a convergent starter have maximum error \(E_0\), the local discrete defect be \(h\,\tau_n\), and \(f\) be Lipschitz with constant \(L\) on the solutions' domain. Repeated substitution using the bounded \(C^j\) first propagates the starter and each past perturbation. The Lipschitz terms contribute a sum of errors. For an implicit step take \(h\) sufficiently small to absorb its newest error term. With constants independent of \(h\),

\[E_n\le C_1(E_0+T\max|\tau_j|)+C_2h\sum_{i<n}E_i \le C_1(E_0+T\max|\tau_j|)\exp(C_2T).\]

Thus consistency and null stability imply convergence. Conversely, convergence for arbitrary convergent starting values on smooth problems forces bounded homogeneous propagation. If a root lies outside the disk, a vanishing initial perturbation can grow exponentially over \(T/h\) steps. For a repeated unit root choose an initial perturbation proportional to \(h^{s-1}\) in the generalised mode so that its final error stays finite and nonzero. Consistency is forced by testing constants and linear-in-time solutions under convergence for all equations, taking an irreducible multistep formula and the usual normalisation. This equivalence concerns fixed-order, constant-step schemes. Changing step ratios changes the propagation matrices.

Control the perturbation before changing the grid

For \(f=0\), take \(\rho=(z-1)(z-r)\), with \(r=-1\) or \(r=2\). Choose \(\sigma=1-r\) to make the associated formulas consistent. Initialise \(y_0=1,y_1=1+h^3\). The exact propagated endpoint error at \(N=1/h\) is

\[e_N=h^3(1-r^N)/(1-r).\]

For \(r=-1\) every error stays \(O(h^3)\). For \(r=2\) the growing factor eventually defeats every algebraic power. Exact starting data with no perturbations would hide this instability in the constant solution.

Transfer the experiment to the decaying state \(y'=-y\) by choosing \(\sigma(z)=(1-r)z\). Now the middle coefficient in the recurrence is \(1+r-h(1-r)\). A OneSimulation RK4 trajectory supplies a common starter and a separate full-step trajectory checked against \(e^{-1}\). Inject \(h^3\) into the starter and compare with the identical multistep solve without that injection. The difference isolates amplification along the recurrence.

"""Resolve a decaying signal with two consistent families of two-step methods."""
import matplotlib.pyplot as plt
import numpy as np
from onesim.numerics.time import ClassicalRungeKutta4TimeIntegrator

def decay(state, time):
    return (-state[0],)

def endpoint(parasitic, starter, h, n):
    previous, current = 1.0, starter
    for _ in range(1, n):
        previous, current = current, (1+parasitic-h*(1-parasitic))*current-parasitic*previous
    return current

method = ClassicalRungeKutta4TimeIntegrator()
counts = [6, 10, 14, 18, 22, 26]
fig, ax = plt.subplots(figsize=(7, 4), layout="constrained")
for parasitic in [-1, 2]:
    errors = []
    for n in counts:
        h = 1/n
        reference = (1.0,)
        starter = method.advance(reference, decay, h, time=0.)[0]
        for j in range(n):
            reference = method.advance(reference, decay, h, time=j*h)
        unperturbed = endpoint(parasitic, starter, h, n)
        perturbed = endpoint(parasitic, starter+h**3, h, n)
        errors.append(abs(perturbed-unperturbed))
        assert abs(reference[0] - np.exp(-1)) < 1e-5
    ax.semilogy(counts, errors, "o-", label=f"Parasitic root {parasitic:+d}")
    print(f"Root {parasitic:+d}: change at T=1 with 26 steps: {errors[-1]:.6g}")
print(f"Reference RK4 error with 26 steps: {abs(reference[0]-np.exp(-1)):.3g}")
ax.set(xlabel="Steps to time 1", ylabel="Final change caused by starting perturbation")
ax.legend()
fig.savefig("numerics-parasitic-root.png", dpi=170)

For \(\rho=(z-1)^2\) and \(f=0\), choose \(e_0=0,e_1=h\). Differences stay equal to \(h\), so \(e_N=Nh=T\). The local residual is exactly zero while the starter converges and the endpoint fails to converge.

Separate the order of the starter from that of the method

Work through the solution

A null-stable order-three formula has \(\tau=O(h^3)\). If its starter has only \(O(h^2)\) accuracy, the bound at fixed \(T\) becomes \(O(h^2)\). Raising the order of the multistep formula alone cannot recover the lost order.
