Cancelling a nuisance coefficient

Suppose a smooth integrand gives

\[T(h)=I+ah^2+bh^4+O(h^6).\]

Halving the mesh gives

\[T(h/2)=I+ah^2/4+bh^4/16+O(h^6).\]

Multiply the second formula by four, subtract the first and divide by three. The unknown \(a\) disappears without being estimated explicitly. The new leading error is \(-bh^4/4\).

At level \(j\) a smooth even-power expansion starts with a power \(h^{2j}\) to be removed from the preceding column. The same two-row elimination yields

\[R_{k,0}=T(2^{-k}h_0),\]
\[R_{k,j}=R_{k,j-1}+\frac{R_{k,j-1}-R_{k-1,j-1}}{4^j-1}.\]

Each refinement reuses all previous function values. Add only the midpoints of old panels, because every old endpoint becomes an even-indexed fine node. This is especially attractive when obtaining a sample means running an expensive smooth simulation.

Background · Richardson extrapolation
\[I\approx I_{h/2}+(I_{h/2}-I_h)/(2^p-1)\]

This cancels an assumed leading error proportional to h to power p. Several refinements can test whether that asymptotic regime is present.

Check the arithmetic twice

For \(\int_0^1 x^4\,dx=1/5\), the first three trapezoidal estimates are 0.5, 0.28125 and 0.220703125. The first extrapolation column contains 0.2083333 and 0.20052083. Combining them with coefficient 15 gives 0.2. This is an exact polynomial check on indexing and column orientation.

For \(\int_0^1\sqrt{x}\,dx=2/3\), the first two trapezoidal values are 0.5 and approximately 0.603553. Their extrapolate is about 0.63807. The derivative is singular at zero. The endpoint panel alone has an error proportional to \(h^{3/2}\), the same scale that dominates the global error. A factor of four cannot cancel it.

Tutorial on interpreting a convergence table

Given three successive estimates with differences 0.008 and 0.002, what observed order do they suggest on uniform bisection?

Worked solution

A factor of four between signed differences is consistent with \(2^p=4\), hence order two. A further refinement tests whether this is an asymptotic regime.

Remove the square-root difficulty by a change of variable. What estimate becomes exact after one extrapolation?

Worked solution

Set \(x=t^2\), \(dx=2t\,dt\). The integral becomes \(\int_0^1 2t^2\,dt\). The raw trapezoidal error for a quadratic has only an \(h^2\) term, so first-column Richardson extrapolation is exact in exact arithmetic.
