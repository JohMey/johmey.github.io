Numerical simulation in Python

OneSimulation is a local Python runtime for CAD import, meshing, physics and numerical solvers. The examples on this site include the model, the code and a reference you can check.

Run the STEP exampleBy Dr. Johannes Meyer

A steel sleeve under 40 MPa tension

The model starts as a STEP file. Quadratic finite elements give 20.49 µm of axial elongation. The uniaxial bar formula gives 20.73 µm. The tutorial shows which face is fixed, where the load acts and how the check was made.

Five methods on one mesh

A 3D Poisson benchmark with a known solution. The table gives RMS errors and wall times for two FEM, one FVM and two FDM discretizations.
