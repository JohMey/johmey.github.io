Model, method and check

In OneSimulation the geometry, physical equation and numerical method are separate objects. In the Poisson test I keep the equation and mesh fixed and swap the spatial discretization. In the STEP example I keep the imported solid and axial load fixed and compare the computed extension with a bar formula.

For every example I publish here, I want a reader to be able to find the inputs, run the code and see what the check measures. The Poisson problem has an exact solution. The sleeve has an approximate reference. That difference matters when interpreting the error.
