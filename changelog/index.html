Runtime Alpha 0.2.1a8

22 November 2026 · current release

  • The MCP server builds new studies from a description: steady heat conduction in rectangular plates and boxes, and linear elasticity in 3D boxes.
  • Ten MCP tools for Codex and Claude Code: create, save, start and read studies, import projects and validate project documents.
  • Packages for macOS (Apple Silicon), Ubuntu 22.04 (x86-64) and Windows x64.

  • Corrected module paths in the optics package.
