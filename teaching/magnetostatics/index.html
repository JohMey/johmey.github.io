Current, flux and vector potential

For steady currents, \(\nabla\times\mathbf H=\mathbf J\) and \(\nabla\cdot\mathbf B=0\). In an isotropic linear medium \(\mathbf B=\mu\mathbf H\), except that remanent magnetisation can contribute an additional term. Writing \(\mathbf B=\nabla\times\mathbf A\) enforces the divergence condition and leads to an equation in \(\mathbf A\).

The transformation \(\mathbf A\mapsto\mathbf A+\nabla\chi\) leaves \(\mathbf B\) unchanged. A vector-potential solve therefore needs a gauge or equivalent treatment of the null space. Continuity of normal \(\mathbf B\) and the prescribed jump in tangential \(\mathbf H\) constrain the material interfaces.

Coils, inductance and open boundaries

A single circular filament of radius \(R\) carrying current \(I\) gives \(B_z=\mu_0IR^2/[2(R^2+z^2)^{3/2}]\) on its axis by the Biot–Savart law. A tightly wound thin coil of \(N\) identical turns multiplies this result by \(N\). In a linear system, an independent inductance check is \(W_m=LI^2/2\).

A finite mesh truncates the air domain. Increase the distance to the truncation surface at fixed mesh resolution near the coil to estimate the boundary error separately from spatial discretization error.

Worked example and lab

For a thin 100-turn coil with \(R=50\) mm and \(I=2\) A, \(B_z(0)=2.51\) mT. At \(z=R\) the field falls by a factor \(2^{-3/2}\) to 0.889 mT.

  1. Run the solenoid-axis notebook and compare samples with the reference appropriate to its coil length.
  2. Double the current in a linear material and check whether the field doubles and energy quadruples.
  3. Repeat with a larger air domain and a finer coil mesh. Report the two changes separately.

Model the physics in OneSimulation

onesim.physics.magnetostatics

Assemble the model from permeability, a formulation and current sources. MagneticVectorPotential(gauge=CoulombGauge()) gives a vector-potential model with a divergence constraint. SolenoidCurrent supplies azimuthal winding current and a meshing support. MagneticInsulation sets tangential potential to zero. The explicit potential, magnetic-field and reluctance boundary declarations represent other tangential boundary models. Use the coil example in Chapter 3 as a starting point. Record the gauge, outer boundary distance and winding mesh size. For a linear material, plot \(B/I\) for several currents on the same axes to verify scaling.

6.13.1 Imposed tangential potential and a uniform magnetic field

Use a known divergence-free vector potential as tangential trace. The resulting flux density is the curl of that field. This example exercises a nonzero trace and the Coulomb constraint.

import numpy as np
import matplotlib.pyplot as plt
import onesimulation_plot_theme as theme
from onesim.cad.d3 import Box
from onesim.materials import VacuumPermeability
from onesim.meshing import StructuredTetrahedralMesher
from onesim.numerics import Numerics
from onesim.numerics.fem import FiniteElement, Nedelec
from onesim.numerics.linear import SparseDirect
from onesim.physics.magnetostatics import (
    CoulombGauge,
    MagneticPotentialBoundary,
    MagneticVectorPotential,
    Magnetostatics,
)
from onesim.simulation import Problem, Simulation

box = Box(length=1, width=1, height=1)
model = Magnetostatics(
    domain=box.volume,
    permeability=VacuumPermeability(),
    formulation=MagneticVectorPotential(
        gauge=CoulombGauge(multiplier_reference_dof=0)
    ),
)


def vector_potential(x, y, z):
    return np.column_stack((-0.5 * y, 0.5 * x, np.zeros_like(x)))


problem = Problem(
    name="Uniform B patch",
    geometry=box,
    physics=(model,),
    boundary_conditions=(
        MagneticPotentialBoundary(
            physics=model, boundary=box.boundaries.all, value=vector_potential
        ),
    ),
)
mesh = StructuredTetrahedralMesher(cells=(2, 2, 2)).generate(box)
result = Simulation(
    problem=problem,
    mesh=mesh,
    numerics=Numerics(
        spatial=FiniteElement(element=Nedelec(1)), linear_solver=SparseDirect()
    ),
).solve_stationary()
x = np.linspace(0.02, 0.98, 101)
p = np.column_stack((x, np.full_like(x, 0.37), np.full_like(x, 0.51)))
B = result.field(model.magnetic_flux_density).evaluate(p)
np.testing.assert_allclose(B, np.broadcast_to((0.0, 0.0, 1.0), B.shape), atol=1e-8)
theme.use_theme()
fig, ax = plt.subplots(figsize=(6.6, 3.3), layout="constrained")
for i, d in enumerate("xyz"):
    ax.plot(x, B[:, i], label=f"B {d}")
ax.set(xlabel="World x [m]", ylabel="Magnetic flux density [T]")
ax.legend(frameon=False)
plt.show()
