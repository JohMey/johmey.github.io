Numerical methods for teaching

A 14-week Python lab with one two-hour session each week. Students begin with radiative cooling and finish by checking a model of their own against an exact or independent reference.

14-week course plan

Weekly lab topics, prerequisites and marking criteria. A shorter seven-session sequence is included.

Eight exercises

Model parameters, reference values and deliverables for time stepping, advection, Poisson solvers and 3D elasticity.

Cooling and oscillator script

Run fourth-order Runge–Kutta and export numerical and exact values as CSV. It uses the Python standard library and covers exercises 1 and 2.

A Computational Atlas

Worked models with geometry, physical assumptions and reference checks. Use it to choose a final-project case.
