Coupled equations and interfaces

Two subsystems with states \(u\) and \(v\) have coupled residuals \(F(u,v)=0\) and \(G(u,v)=0\). If \(F\) depends on \(v\) but \(G\) is independent of \(u\), solve \(G\) first and transfer \(v\). Strong two-way coupling can require iteration or a monolithic solve. In a monolithic Newton method the off-diagonal Jacobian blocks represent the response of each residual to the other state.

At a thermal interface without storage, the heat flux leaving one side equals the flux entering the other. Perfect contact also enforces equal temperature; finite contact conductance instead gives \(q''=h_c(T_a-T_b)\). Across unrelated meshes, interpolation preserves pointwise patterns approximately, while a conservative transfer targets an integral balance.

Thermoelasticity

An isotropic solid at temperature change \(\Delta T\) has thermal strain \(\boldsymbol\epsilon_T=\alpha\Delta T\mathbf I\). In small-strain elasticity the stress is computed from the elastic part \(\boldsymbol\epsilon-\boldsymbol\epsilon_T\). Heating a free bar creates expansion with zero axial stress; restraining both ends creates compression. Separate thermal and mechanical boundary conditions in the model.

Worked example and lab

A 100 mm steel bar with \(\alpha=12\times10^{-6}\) K⁻¹ and \(\Delta T=50\) K has a free extension of 60 µm. For a uniaxial bar with zero axial strain and \(E=200\) GPa, the stress is \(-120\) MPa when tension is positive.

  1. Compare free and axially restrained models at the same temperature. Attribute reaction forces to the chosen supports.
  2. Repeat with a spatially varying temperature. Compare the field integral before and after transfer to the mechanical mesh.
  3. For a genuinely two-way case from the recipes, report both subsystem residuals and the interface flux mismatch.

Model the physics in OneSimulation

onesim.physics.multiphysics

Use HeatedResistor, FluidColumnPiston, VoiceCoil, ThermalExchange or AdiabaticReaction for a packaged lumped balance. These models expose typed states and inputs. For example, a voice coil couples electrical current to force and mechanical velocity to back electromotive force. Initialize current, displacement and velocity, and plot all three against time. For thermal exchange with zero external power, check constancy of \(C_1T_1+C_2T_2\) and the exponential decay of \(T_1-T_2\).

For independently declared physics, compose a Problem with both models, attach conditions to their owners and connect typed fields via FieldCoupling. Select each mesh and Numerics by model identity. The physical link specifies what is transmitted. The numerical transfer specifies how to represent it on the target support. A coupling strategy specifies when to solve each block. For thermoelasticity, use thermal temperature as the source and the elastic model's temperature input as the target, with FiniteElementEvaluation() to evaluate at mechanical quadrature points. Enable IsotropicThermalExpansion(reference_temperature=...) in the elastic model. test_fe_thermoelastic_coupling.py checks free expansion and restrained thermal stress. The electrothermal, thermomechanical, fluid–structure and general coupled service exports carry separate configuration and provider contracts.

5.13.1 Transfer a temperature to mechanical quadrature

This stationary test holds the faces at a uniform temperature above the stress-free reference and clamps all displacement components. The expected normal stress is \(-E\alpha\Delta T/(1-2\nu)\). The separate FE spaces share a mesh here. The coupling still evaluates the thermal field on the receiver's quadrature rather than copying coefficients.

import numpy as np
from onesim.cad.d3 import Box
from onesim.materials import IsotropicSolid
from onesim.meshing import StructuredTetrahedralMesher
from onesim.numerics import Numerics
from onesim.numerics.fem import FiniteElement, Lagrange
from onesim.numerics.field_transfer import FiniteElementEvaluation
from onesim.numerics.linear import SparseDirect
from onesim.physics.heat_transfer import FixedTemperature, HeatConduction
from onesim.physics.solid_mechanics import (
    FixedDisplacement, IsotropicThermalExpansion, LinearElasticity,
)
from onesim.simulation import Problem, Simulation
from onesim.simulation.field_connections import FieldCoupling

box = Box(length=1, width=1, height=1)
mesh = StructuredTetrahedralMesher(cells=(2, 2, 2)).generate(box)
E, nu, alpha = 100.0, 0.3, 1e-5  # Pa, 1, 1/K
T_ref, T_wall = 300.0, 320.0
material = IsotropicSolid(
    density=1, specific_heat_capacity=1, thermal_conductivity=1,
    youngs_modulus=E, poisson_ratio=nu, thermal_expansion_coefficient=alpha,
)
heat = HeatConduction(domain=box.volume, material=material)
solid = LinearElasticity(
    domain=box.volume, material=material,
    thermal_strain=IsotropicThermalExpansion(reference_temperature=T_ref),
)
problem = Problem(
    name="Constrained heating", geometry=box, physics=(heat, solid),
    boundary_conditions=(
        FixedTemperature(boundary=box.boundaries.all, physics=heat, value=T_wall),
        FixedDisplacement(boundary=box.boundaries.all, physics=solid, value=(0, 0, 0)),
    ),
    couplings=(FieldCoupling(
        source=heat.temperature, target=solid.temperature,
        transfer=FiniteElementEvaluation(),
    ),),
)
sim = Simulation(
    problem=problem, mesh={heat: mesh, solid: mesh},
    numerics={
        m: Numerics(spatial=FiniteElement(element=Lagrange(order=p)),
                    linear_solver=SparseDirect())
        for m, p in ((heat, 1), (solid, 2))
    },
)
sim.validate().require_valid()
result = sim.solve_stationary()
point = [[0.2, 0.3, 0.4]]
expected = -E * alpha * (T_wall - T_ref) / (1 - 2*nu)
np.testing.assert_allclose(result.field(heat.temperature).evaluate(point), [T_wall])
np.testing.assert_allclose(result.field(solid.displacement).evaluate(point), [[0, 0, 0]],
                           atol=1e-12)
sigma = result.field(solid.stress).evaluate(point)[0]
np.testing.assert_allclose(sigma, [expected]*3 + [0]*3, atol=1e-10)

import matplotlib.pyplot as plt
import onesimulation_plot_theme as theme

x = np.linspace(.01,.99,101)
points = np.column_stack((x,np.full_like(x,.3),np.full_like(x,.4)))
temperature = result.field(heat.temperature).evaluate(points)
normal_stress = result.field(solid.stress).evaluate(points)[:,0]
theme.use_theme()
fig,(a,b)=plt.subplots(2,1,sharex=True,figsize=(6.8,3.8),layout="constrained")
a.plot(x,temperature);a.set_ylabel("Temperature [K]")
b.plot(x,normal_stress);b.set(xlabel="World x [m]",ylabel="Normal stress [Pa]")
plt.show()

The low modulus makes this a simple manufactured balance in SI units. To build a free-expansion variant, change the supports to remove rigid-body motion while allowing thermal expansion. Then check displacement and stress against the corresponding physical reference.

6.15.1 Joule heating with temperature-dependent resistance

Apply a voltage and use a linear resistance law around a stated reference temperature. The heating and current histories expose the electrical feedback.

from onesim.physics.multiphysics import HeatedResistor

domain = LumpedDomain()
model = HeatedResistor(
    domain=domain.system,
    resistance=2,
    heat_capacity=5,
    applied_voltage=2,
    temperature_coefficient=0.01,
    reference_temperature=300,
)
t, data = history_case(
    domain,
    model,
    dict(temperature=300.0),
    ("temperature", "current", "joule_power"),
    end=4,
    dt=0.02,
)
assert data["temperature"][-1] > 300 and data["current"][-1] < data["current"][0]
fig = history_plot(
    "Joule heating with temperature-dependent resistance", model, t, data
)
plt.show()

6.15.4 Heat transfer between two capacities

The conductance transfers energy from the hotter capacity to the cooler one. Check conservation by adding their stored thermal energies.

from onesim.physics.multiphysics import ThermalExchange

domain = LumpedDomain()
model = ThermalExchange(
    domain=domain.system,
    first_capacity=2,
    second_capacity=3,
    conductance=0.5,
)
t, data = history_case(
    domain,
    model,
    dict(first_temperature=320.0, second_temperature=300.0),
    ("first_temperature", "second_temperature", "heat_flow"),
    end=4,
    dt=0.02,
)
np.testing.assert_allclose(
    2 * data["first_temperature"] + 3 * data["second_temperature"], 1540.0, atol=1e-9
)
fig = history_plot("Heat transfer between two capacities", model, t, data)
plt.show()

6.15.5 Heating from a homogeneous reaction

Combine a homogeneous reaction network and a temperature balance. This run specifies an independent volumetric heat source and a reaction with zero specified energy release, so the concentration sum and temperature rise have separate exact checks.

from onesim.physics.chemistry import ReactionIR, ReactionNetworkIR, SpeciesIR
from onesim.physics.multiphysics import AdiabaticReaction

domain = LumpedDomain()
species = tuple(
    SpeciesIR(n, 0, 1.66054e-27, composition=(("H", 1),)) for n in ("A", "B")
)
reaction = ReactionIR(
    "conversion", (("A", 1),), (("B", 1),), {"kind": "constant", "value": 0.3}
)
network = ReactionNetworkIR("reactive heating", "1", species, (reaction,))
model = AdiabaticReaction(
    domain=domain.system,
    network=network,
    volumetric_heat_capacity=2.0,
    thermal_source=0.4,
)
a, b = model.concentration("A").name, model.concentration("B").name
t, data = history_case(
    domain,
    model,
    {a: 1.0, b: 0.0, "temperature": 300.0},
    (a, b, "temperature"),
    end=2,
    dt=0.01,
)
np.testing.assert_allclose(data[a] + data[b], 1, atol=1e-12)
np.testing.assert_allclose(data["temperature"], 300 + 0.2 * t, atol=1e-9)
fig = history_plot("Reacting mixture with imposed heating", model, t, data)
plt.show()

6.15.6 Electrothermal provider with Joule heat

The temperature-dependent conductivity changes the current density and Joule power in a prescribed electric field. Inspect the thermal and electrical outputs on the same coordinates.

from onesim.physics.multiphysics import (
    ElectroThermalConfiguration,
    ElectroThermalPublicApi,
)

n = 32
x0 = np.linspace(0, 1, n, endpoint=False)
wave = np.sin(2 * np.pi * x0)
configuration = ElectroThermalConfiguration(
    parameters=dict(
        cell_count=n,
        final_time=0.01,
        time_step=0.0001,
        initial_temperature=300 + wave,
        applied_electric_field=2,
        conductivity_temperature_coefficient=0.02,
        reference_temperature=300,
    )
)
result = run_service(ElectroThermalPublicApi(), configuration)
fig = service_figure(
    "Electrothermal provider with Joule heat",
    result.coordinates,
    "Provider coordinate [m]",
    ("Temperature [K]", result.temperature),
    ("Joule heat [W/m3]", result.joule_heat),
)
plt.show()

6.15.10 Monolithic versus partitioned linear exchange

Describe the block partition separately from its system matrix. The selected monolithic strategy integrates the two-state exchange and returns a derivative for each block.

from onesim.physics.multiphysics import (
    GeneralCoupledSubsystemsConfiguration,
    GeneralCoupledSubsystemsPublicApi,
)

settings = dict(
    subsystem_ids=("a", "b"),
    subsystem_sizes=(1, 1),
    system_matrix=((-1.0, 1.0), (1.0, -1.0)),
    initial_state=(1.0, 0.0),
    final_time=0.1,
    time_step=0.01,
)
result = run_service(
    GeneralCoupledSubsystemsPublicApi(),
    GeneralCoupledSubsystemsConfiguration(parameters=settings),
)
fig = service_figure(
    "Monolithic versus partitioned linear exchange",
    np.arange(2),
    "Subsystem index",
    ("State [1]", result.state.values),
    ("Rate [1/s]", result.derivative),
)
plt.show()

6.15.11 Reactive coupling facade with an explicit species registry

The facade requires a species set, reaction network, initial density arrays and initial temperature. Begin with zero reactions to isolate conservative diffusion. Add balanced reaction channels only after the transport check.

from onesim.physics.multiphysics import (
    ReactiveCouplingConfiguration,
    ReactiveCouplingPublicApi,
)
from onesim.physics.plasma.collisions.models.reactions import ReactionNetwork
from onesim.physics.plasma.fluid.models.declarations.species.species import (
    SpeciesDefinition,
    SpeciesSet,
)

n = 32
x0 = np.linspace(0, 1, n, endpoint=False)
species = SpeciesSet(
    (SpeciesDefinition("A", "Tracer", charge_number=0, mass=1.66e-27),)
)
initial = 1e16 * (1 + 0.1 * np.cos(2 * np.pi * x0))
configuration = ReactiveCouplingConfiguration(
    parameters=dict(
        species=species,
        reaction_network=ReactionNetwork(),
        initial_densities={"A": initial},
        initial_temperature=np.full(n, 300.0),
        default_species_diffusivity=0.01,
        thermal_diffusivity=0.02,
        final_time=0.01,
        time_step=0.0001,
    )
)
result = run_service(ReactiveCouplingPublicApi(), configuration)
fig = service_figure(
    "Conservative species transport",
    result.coordinates,
    "Coordinate [m]",
    ("Species A [m-3]", result.densities["A"]),
    ("Temperature [K]", result.temperature),
)
plt.show()
