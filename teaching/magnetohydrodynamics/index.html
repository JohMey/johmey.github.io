Conducting fluids in magnetic fields

A moving conductor generates current, and that current alters the fluid momentum. In resistive magnetohydrodynamics (MHD), the Lorentz force density is \(\mathbf J\times\mathbf B\), with \(\mathbf J=(\nabla\times\mathbf B)/\mu_0\) when displacement current is neglected. For constant magnetic diffusivity \(\eta_m=1/(\mu_0\sigma)\), the magnetic field obeys

\[\partial_t\mathbf B=\nabla\times(\mathbf u\times\mathbf B)+\eta_m\nabla^2\mathbf B, \qquad \nabla\cdot\mathbf B=0.\]

The magnetic Reynolds number \(Rm=UL/\eta_m\) compares induction by motion with diffusion. For \(Rm\ll1\), the perturbation to an imposed magnetic field can often be neglected, while the Lorentz force remains important. An electric potential then enforces \(\nabla\cdot\mathbf J=0\) for \(\mathbf J=\sigma(-\nabla\phi+\mathbf u\times\mathbf B)\).

Hartmann layers

In channel flow with magnetic field perpendicular to the plates, the Hartmann number \(Ha=B_0L\sqrt{\sigma/(\rho\nu)}\) compares magnetic braking with viscous effects. For \(Ha\gg1\) and \(L\) the half-gap, the characteristic Hartmann layer thickness is \(L/Ha\). Specify both mechanical wall conditions and whether current can cross each wall.

Worked example and lab

Take \(L=0.01\) m, \(B_0=0.2\) T, \(\sigma=10^6\) S/m, \(\rho=6000\) kg/m³ and \(\nu=5\times10^{-7}\) m²/s. Then \(Ha\approx36.5\) and the estimated layer thickness is 0.274 mm. At \(U=0.1\) m/s, \(Rm\approx1.26\times10^{-3}\), illustrating the separation between induction and braking.

  1. Run the Hartmann duct notebook; identify walls normal and parallel to the magnetic field.
  2. Measure the velocity profile and current balance. Repeat with added resolution normal to the thin layers.
  3. Compare zero field with finite field at the same pressure gradient and state what the wall electrical conditions imply for current closure.

Model the physics in OneSimulation

onesim.physics.magnetohydrodynamics

TransverseMHDWaves evolves two velocity and two magnetic perturbations along a background field. Start with periodic endpoints and a single polarization, then add the second. The nominal ideal Alfv\'en speed is \(|B_0|/\sqrt{\rho\mu}\). Compare both propagation direction and component amplitudes. The FD, FV and DG examples in test_transverse_mhd_method_flexibility.py include a rotated line, conservation checks and comparison on the actual carrier. InductionlessMomentum uses a fixed field in the inductionless regime and a dedicated no-slip condition. TwoFluidExchange and RadiationMatterExchange are homogeneous exchange models. Initialize both sides of the exchange and test momentum or energy transfer with externally imposed sources accounted for. The result adapters cover additional provider result families. Their names indicate result types and by themselves give no model construction recipe.

# Use run_periodic_line from this chapter.
from onesim.numerics.fdm import FiniteDifference, PolynomialDifference
from onesim.physics.magnetohydrodynamics import TransverseMHDWaves

line = Line(start=(0, 0, 0), end=(2*np.pi, 0, 0))
wave = TransverseMHDWaves(
    domain=line.line, density=2.0, permeability=0.5, longitudinal_field=1.0,
)
result = run_periodic_line(
    line, wave,
    ((wave.velocity_y, lambda x: 0.1*np.sin(x)), (wave.velocity_z, 0.0),
     (wave.magnetic_y, lambda x: -0.1*np.sin(x)), (wave.magnetic_z, 0.0)),
    Numerics(spatial=FiniteDifference(gradient=PolynomialDifference()),
             time_integrator=ClassicalRungeKutta4()),
    cells=48, end=0.05, dt=0.001,
)
u = result.field(wave.velocity_y)
x = u.space.dof_coordinates[:, 0]
np.testing.assert_allclose(u.values, 0.1*np.sin(x - 0.05), atol=5e-4, rtol=0)

import matplotlib.pyplot as plt
import onesimulation_plot_theme as theme

b = result.field(wave.magnetic_y)
theme.use_theme()
fig,ax=plt.subplots(figsize=(6.8,3.4),layout="constrained")
ax.plot(x,u.values,label="Transverse velocity y")
ax.plot(x,b.values,label="Transverse magnetic field y")
ax.set(xlabel="World x [m]",ylabel="Amplitude in test units")
ax.legend(frameon=False)
plt.show()

6.12.1 Drag-mediated two-fluid exchange

Two homogeneous components exchange momentum through drag. Without external forces the density-weighted velocity sum stays fixed.

from onesim.physics.magnetohydrodynamics import TwoFluidExchange

domain = LumpedDomain()
model = TwoFluidExchange(
    domain=domain.system,
    density_one=2,
    density_two=3,
    drag_coefficient=0.4,
)
t, data = history_case(
    domain,
    model,
    dict(velocity_one=0.5, velocity_two=-0.2, energy_one=0.1, energy_two=0.1),
    ("velocity_one", "velocity_two", "energy_one"),
    end=2,
    dt=0.01,
)
np.testing.assert_allclose(
    2 * data["velocity_one"] + 3 * data["velocity_two"], 0.4, atol=1e-10
)
fig = history_plot("Drag-mediated two-fluid exchange", model, t, data)
plt.show()

6.12.2 Homogeneous radiation and matter exchange

Initialize matter and radiation energies independently. Their sum remains constant in the isolated model and temperature follows the matter energy.

from onesim.physics.magnetohydrodynamics import RadiationMatterExchange

domain = LumpedDomain()
model = RadiationMatterExchange(
    domain=domain.system,
    heat_capacity=2,
    absorption=0.3,
    light_speed=4,
    radiation_constant=0.1,

6.12.3 Decay of velocity with Lorentz damping

The selected pressure gradient and applied electric field cancel the constant part of the force. A sinusoidal profile decays through viscosity and electromagnetic drag.

from onesim.physics.magnetohydrodynamics import (
    InductionlessMomentum,
    InductionlessNoSlipWall,
)
from onesim.numerics.fdm import PolynomialLaplacian

line = Line(start=(0, 0, 0), end=(1, 0, 0))
model = InductionlessMomentum(
    domain=line.line,
    density=2,
    kinematic_viscosity=0.03,
    conductivity=1.5,
    magnetic_field=0.8,
    electric_field=0.2,
    pressure_gradient=0.24,
)
conditions = tuple(
    InductionlessNoSlipWall(physics=model, boundary=getattr(line.boundaries, side))
    for side in ("start", "end")
)
end = 0.12
result = line_experiment(
    line,
    model,
    dict(velocity=lambda x: 0.1 * np.sin(np.pi * x)),
    FiniteDifference(diffusion=PolynomialLaplacian()),
    cells=36,
    end=end,
    dt=0.0005,
    conditions=conditions,
)
u = result.field(model.velocity).values
np.testing.assert_allclose(
    result.field(model.current_density).values, 1.5 * (0.2 + 0.8 * u)
)
exact = (
    lambda x: 0.1
    * np.sin(np.pi * x)
    * np.exp(-(0.03 * np.pi**2 + 1.5 * 0.8**2 / 2) * end)
)
fig = profile_figure(
    "Viscous and Lorentz damping",
    result,
    model,
    ("velocity", "current_density", "lorentz_force"),
    reference={"velocity": exact},
)
plt.show()

6.12.4 Provider-selected radiation and matter exchange

Use the public provider ID to select a reduced MHD-family kernel. This example reads the provider's cell arrays and checks exchange conservation. Provider IDs advertised as pending describe extension slots.

from onesim.physics.magnetohydrodynamics import MagnetohydrodynamicPublicApi

api = MagnetohydrodynamicPublicApi()
key = "radiation_matter_exchange_1d"
assert key in api.provider_ids()
provider = api.create_provider(key)
result = provider.run(
    matter_energy=1.0 + 0.1 * np.sin(np.linspace(0, 2 * np.pi, 64, endpoint=False)),
    radiation_energy=np.full(64, 0.1),
)
np.testing.assert_allclose(result.total_energy_residual, 0, atol=1e-8)
fig = service_figure(
    "MHD provider radiation exchange",
    np.arange(64),
    "Native cell index",
    ("Matter energy", result.matter_energy),
    ("Radiation energy", result.radiation_energy),
)
plt.show()

6.12.5 The provider catalogue and its execution status

The registry advertises 74 provider IDs. This checkout marks 27 implemented, 1 partial and 46 pending. The galleries below exercise the implemented entries and the executable reduced relativistic variant. Each panel plots a real result array with its own scale. The shared conservative seed is in the order density, two momenta, total energy and two magnetic components. It uses a ratio of specific heats of 1.4. The routes with their own default state use that state and expose the selected native diagnostic.

import numpy as np
import matplotlib.pyplot as plt
import onesimulation_plot_theme as theme
from onesim.physics.magnetohydrodynamics import MagnetohydrodynamicPublicApi


def conservative_mhd_seed(n):
    x, y = np.meshgrid(
        np.linspace(0, 1, n, endpoint=False),
        np.linspace(0, 1, n, endpoint=False),
        indexing="ij",
    )
    density = 1 + 0.05 * np.cos(2 * np.pi * x)
    pressure = 1 + 0.04 * np.cos(2 * np.pi * y)
    mx = density * 0.05 * np.sin(2 * np.pi * y)
    my = density * 0.03 * np.cos(2 * np.pi * x)
    bx = 0.2 + 0.03 * np.sin(2 * np.pi * y)
    by = 0.1 + 0.03 * np.cos(2 * np.pi * x)
    energy = (
        pressure / 0.4 + (mx * mx + my * my) / (2 * density) + (bx * bx + by * by) / 2
    )
    return density, mx, my, energy, bx, by


def provider_gallery(quantities, *, seeded=False):
    theme.use_theme()
    rows = (len(quantities) + 1) // 2
    fig, axes = plt.subplots(
        rows, 2, squeeze=False, figsize=(7.3, 2.35 * rows), layout="constrained"
    )
    for ax, (key, quantity) in zip(axes.ravel(), quantities.items()):
        if seeded:
            p = MagnetohydrodynamicPublicApi.create_provider(
                key, mesh_size=16, final_time=0.002, time_step=0.0002
            )
            result = p.run(initial_state=conservative_mhd_seed(16))
        else:
            p = MagnetohydrodynamicPublicApi.create_provider(key)
            result = p.run()
        values = np.asarray(getattr(result, quantity))
        assert values.ndim in (1, 2, 3) and np.isfinite(values).all()
        label = quantity.replace("_", " ")
        if values.ndim == 3:
            values = values[:, :, values.shape[2] // 2]
            label += " (mid-plane)"
        if values.ndim == 1:
            ax.plot(np.arange(values.size), values)
            ax.set(xlabel="Native cell index", ylabel=label)
            ax.grid(alpha=0.25)
        else:
            image = ax.imshow(
                values.T, origin="lower", cmap=theme.FIELD, interpolation="nearest"
            )
            ax.set(xlabel="First array index", ylabel="Second array index")
            fig.colorbar(image, ax=ax, label=label)
        ax.set_title(key.replace("_", " "), fontsize=9)
    for ax in axes.ravel()[len(quantities) :]:
        ax.set_visible(False)
    return fig
