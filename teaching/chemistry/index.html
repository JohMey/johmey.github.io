Species balances and reaction rates

For a closed, well-mixed batch reactor of constant volume, the concentration of species \(i\) satisfies \(\dot c_i=\sum_j\nu_{ij}r_j(\mathbf c,T)\). Each stoichiometric coefficient \(\nu_{ij}\) is negative for a reactant and positive for a product. A linear combination \(\ell^T\mathbf c\) remains constant whenever \(\ell^T\nu=0\). These invariants provide checks independent of the kinetic model.

For \(A\rightarrow B\) with first-order rate \(kc_A\), integrating \(\dot c_A=-kc_A\) gives \(c_A(t)=c_{A0}e^{-kt}\). In the reversible case \(A\rightleftharpoons B\), the relaxation rate is \(k_f+k_r\) and at equilibrium \(c_B/c_A=k_f/k_r\).

Temperature, transport and stiffness

The Arrhenius law \(k=A\exp[-E_a/(RT)]\) uses absolute temperature and activation energy per mole. A small temperature change can significantly change \(k\). Exothermic reaction and heat removal can introduce a second timescale. If important processes evolve at very different rates, compare a stable implicit integrator against explicit steps sufficiently small to resolve the fastest decay.

A tubular reactor also transports species. Its cross-section-averaged equation adds axial advection and, where needed, axial dispersion. Choose boundary conditions from the flux balance at the inlet and outlet rather than applying the batch initial conditions in space.

Worked example and lab

With \(c_{A0}=2\) mol/L and \(k=0.2\) s⁻¹, the half-life is \(3.466\) s and \(c_A(10~\mathrm{s})=0.271\) mol/L. With \(c_{B0}=0\), \(c_B(10~\mathrm{s})=1.729\) mol/L.

  1. Run the first-order decay notebook and compare substrate and product against the exact curves.
  2. Change (k) by a factor of ten and compare trajectories at the same dimensionless time (kt).
  3. Use the reversible case to verify conservation of (A+B) and find the new relaxation timescale. Record the smallest concentration as a check on positivity.

Model the physics in OneSimulation

onesim.physics.chemistry

Choose SpeciesTransport for line advection, diffusion and decay. Use a TransportSpecies entry per stable species ID and obtain each field with model.concentration(species_id). Initialize all transported concentrations on the same spatial support. Set diffusivity in m\(^2\)/s and first-order decay in s\(^{-1}\). A periodic Fourier mode translates at the prescribed velocity and attenuates at a rate given by diffusion plus decay. For an open domain include boundary transport in the budget. For FD, FV, H1 and DG variants see test_species_transport_flexibility.py.

# Use run_periodic_line from this chapter.
from onesim.numerics.fvm import FiniteVolume, MUSCL, Rusanov, TwoPointDiffusion
from onesim.physics.chemistry import SpeciesTransport, TransportSpecies

line = Line(start=(0, 0, 0), end=(2*np.pi, 0, 0))
v, diffusion, decay = 0.6, 0.03, 0.2
transport = SpeciesTransport(
    domain=line.line, velocity=v,
    species=(TransportSpecies("tracer", diffusivity=diffusion, decay_rate=decay),),
)
tracer = transport.concentration("tracer")
n, t = 48, 0.1
result = run_periodic_line(
    line, transport, ((tracer, lambda x: 2 + np.cos(x)),),
    Numerics(
        spatial=FiniteVolume(convection=Rusanov(), reconstruction=MUSCL(),
                             diffusion=TwoPointDiffusion()),
        time_integrator=ClassicalRungeKutta4(),
    ),
    cells=n, end=t, dt=0.001,
)
field = result.field(tracer)
x = field.space.dof_coordinates[:, 0]
exact = np.exp(-decay*t) * (
    2 + np.sinc(1/n) * np.exp(-diffusion*t) * np.cos(x - v*t)
)
np.testing.assert_allclose(field.values, exact, atol=0.002, rtol=0)

import matplotlib.pyplot as plt
import onesimulation_plot_theme as theme

theme.use_theme()
fig, ax = plt.subplots(figsize=(6.8,3.4),layout="constrained")
ax.plot(x, exact, "--", label="Cell-average reference")
ax.plot(x, field.values, ".", label="Species transport")
ax.set(xlabel="World x [m]",ylabel=f"Tracer [{tracer.unit}]")
ax.legend(frameon=False)
plt.show()

For homogeneous kinetics, build ReactionNetworkIR from species and reaction declarations, use ReactionKinetics, and initialize each transported number density. Chemistry and ChemistryKinetics describe the evaluation contract for the network. Check stoichiometric invariants and the rate-law units before choosing a time integrator. Strongly separated reaction times suggest comparing against a small-step reference and using an implicit stage with a compatible rate derivative. LumpedElectrode composes Butler–Volmer reactions and a double layer. LumpedBattery uses BatteryChemistry for open-circuit and resistance closures. Plot voltage, state of charge and temperature against time using a clearly stated current sign. See test_kinetics_input_flexibility.py for a network-driven global model.

6.6.1 Driven redox electrode

Use explicit stoichiometry, an equilibrium-potential closure, and a current density. Track the overpotential through the electrode potential and the transfer of material between species.

from onesim.physics.chemistry import LumpedElectrode, ElectrochemicalReaction

domain = LumpedDomain()
model = LumpedElectrode(
    domain=domain.system,
    reactions=(
        ElectrochemicalReaction("redox", {"A": -1, "B": 1}, 0.1, lambda c, T: 0.0),
    ),
    area=0.01,
    volume=0.001,
    double_layer_capacitance=1,
    applied_current_density=0.05,
)
t, data = history_case(
    domain,
    model,
    dict(potential=0.0, concentration_A=1.0, concentration_B=1.0),
    ("potential", "faradaic_current_density", "concentration_B"),
    end=1,
    dt=0.005,
)
assert data["concentration_B"][-1] > data["concentration_B"][0]
fig = history_plot("Driven redox electrode", model, t, data)
plt.show()

6.6.2 Constant-current battery discharge

Use a state-dependent open-circuit voltage and constant internal resistance. A positive current removes charge and generates ohmic heat.

from onesim.physics.chemistry import LumpedBattery, BatteryChemistry

domain = LumpedDomain()
model = LumpedBattery(
    domain=domain.system,
    chemistry=BatteryChemistry("cell", lambda s, T: 3 + 0.2 * s, lambda s, T: 0.4),
    charge_capacity=10,
    current=0.3,
    thermal_capacity=2,
    heat_transfer=0.5,
    ambient_temperature=300,
)
t, data = history_case(
    domain,
    model,
    dict(state_of_charge=0.7, temperature=300.0),
    ("state_of_charge", "terminal_voltage", "temperature"),
    end=2,
    dt=0.01,
)
np.testing.assert_allclose(data["state_of_charge"], 0.7 - 0.03 * t, atol=1e-9)
fig = history_plot("Constant-current battery discharge", model, t, data)
plt.show()

6.6.3 Closed isomerization reaction

Declare atom-balanced species and one reaction. The constant rate coefficient multiplies the reactant number density. Number density moves between the two species while their sum stays fixed.

from onesim.physics.chemistry import (
    ReactionIR,
    ReactionKinetics,
    ReactionNetworkIR,
    SpeciesIR,
)

domain = LumpedDomain()
species = tuple(
    SpeciesIR(n, 0, 1.66054e-27, composition=(("H", 1),)) for n in ("A", "B")
)
reaction = ReactionIR(
    "conversion", (("A", 1),), (("B", 1),), {"kind": "constant", "value": 0.3}
)
network = ReactionNetworkIR("isomers", "1", species, (reaction,), strict_balance=True)
model = ReactionKinetics(domain=domain.system, network=network)
a, b = model.concentration("A").name, model.concentration("B").name
t, data = history_case(domain, model, {a: 1.0, b: 0.0}, (a, b), end=2, dt=0.01)
np.testing.assert_allclose(data[a], np.exp(-0.3 * t), atol=1e-9)
np.testing.assert_allclose(data[a] + data[b], 1, atol=1e-12)
fig = history_plot("Closed isomerization", model, t, data)
plt.show()
