A diagonal measurement direction

Given \(B=I\), \(s=(1,1)^T\), \(y=(3,1)^T\), compute Broyden's updated matrix. Verify the new secant equation and its action on \((1,-1)^T\).

Worked solution

The discrepancy is \((2,0)^T\) and \(s^Ts=2\). The correction is \(\left(\begin{smallmatrix}1&1\\0&0\end{smallmatrix}\right)\), giving \(B_{\rm new}=\left(\begin{smallmatrix}2&1\\0&1\end{smallmatrix}\right)\).

Multiplication by \(s\) yields \((3,1)^T\). Multiplication by \((1,-1)^T\) yields \((1,-1)^T\), unchanged because that vector is perpendicular to the observed step.

A new measurement can disturb an old one

Suppose \(B=\operatorname{diag}(2,1)\) already predicts the action of \(A=\operatorname{diag}(2,3)\) on \(e_1\). Take \(s=(1,1)^T\), compute the updated matrix, and check both secant directions. Which subsequent probe would measure the second column directly?

Worked solution

The new measured change is \((2,3)^T\) while \(Bs=(2,1)^T\), so add \(\left(\begin{smallmatrix}0&0\\1&1\end{smallmatrix}\right)\). The new matrix is \(\left(\begin{smallmatrix}2&0\\1&2\end{smallmatrix}\right)\).

Its action on \((1,1)^T\) is exact but its action on \(e_1\) is now \((2,1)^T\) rather than \((2,0)^T\). Taking \(s=e_2\) would directly observe \(Ae_2=(0,3)^T\), independently of the first column.

Budget an inner defect

For \(f=x^2-4\) at \(x=2.1\), an inner solver returns \(s=-0.095\). Compute its linear defect, forcing ratio and true new residual. If the target forcing ratio were 0.02, would this step meet the target?

Worked solution

\(f=0.41\), \(f'=4.2\), so the defect is \(0.41-4.2(0.095)=0.011\) and the ratio is \(0.011/0.41\approx0.02683\).

At \(x+s=2.005\), the residual is \(0.020025=0.011+0.095^2\). The permitted linear defect would be \(0.0082\), so this step misses the inner tolerance despite substantially reducing the outer residual.
