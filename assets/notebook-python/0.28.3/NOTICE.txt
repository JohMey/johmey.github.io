This directory distributes the Pyodide 0.28.3 browser runtime.
Upstream source and build recipes: https://github.com/pyodide/pyodide/tree/0.28.3
Upstream distribution: https://cdn.jsdelivr.net/pyodide/v0.28.3/full/
The package versions and archive SHA-256 digests are in pyodide-lock.json.
The CPython, Emscripten, Pyodide and OpenBLAS license notices are provided
beside the runtime. The numerical and plotting wheels include their original
license notices in their .dist-info directories.
